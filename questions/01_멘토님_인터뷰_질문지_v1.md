# 멘토님(담당자님) 인터뷰 질문지 v1

- 작성일: 2026-11-05
- 목적: 기존 "프로모션 기획 도우미"의 업무 흐름을 실제 업무 기준으로 확인하고, 통합 툴 AMOREAD(가제)의 설계 가정을 검증한다.
- 관련 문서: `plans/01_AMOREAD_통합_구현계획_v0.1.md` (질문 ID가 구현 작업과 연결되어 있음)

## 진행 방법

1. **최근 기획 2~3건을 화면으로 보여주시며 처음부터 끝까지 설명해 달라고 요청한다.** (명분 정하기 → 할인 → 페이지 → 디자이너 전달 → 오픈)
2. 설명 중에 답이 나오지 않은 질문만 아래에서 골라 묻는다.
3. ★ 표시 질문(12개)은 반드시 확인한다. 예상 소요 시간은 30~40분이다.
4. 자료를 보여주실 때는 **원가·고객정보·계정정보를 가린 상태**로 부탁드린다. 녹음·캡처는 사전에 동의를 받는다.
5. 답변은 각 표의 '답변 메모' 칸에 적는다. 직접 들은 사실과 내가 해석한 내용은 구분해서 적는다.
