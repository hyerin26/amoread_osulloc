합의 (2026-11-06, 통합 세션 동의)
- app.css는 디자인 세션이 맡는다. 통합 세션은 4차에서 app.css를 고치지 않는다.
- 4차의 '화면 문구 정리'는 기존 화면 JS와 Python 알림의 문구만 고친다. 마크업, `id=`, `data-`는 건드리지 않는다.
- am.css의 칩·배지·상태 표시는 `--r-pill`을 쓰므로, P1에서 `tokens.css`의 `--r-pill`을 8px로 바꾸면 am.css를 고치지 않아도 알약 모양이 없어진다. 버튼·칩의 999px는 ds.css에서 고친다.
- 새 화면은 3장의 공통 클래스로 만들고, 공통 역할이 없는 배치용 클래스만 am.css에 둔다.
- AMOREAD 화면 구조 변경 명세는 통합 세션이 사용자 확인을 거친 뒤 반영한다.
- P1 시작 전에 통합 세션에 알린다. 서버 재시작 없이 새로고침으로 반영된다.
