## 1. 신규 편집기 검토

### 1-1. 좋아진 점 (유지 추천)
- **왼쪽 목록 · 가운데 미리보기 · 오른쪽 속성** 3단 구조가 디자인 툴과 같아서 처음 봐도 익숙해요. 기존 편집기보다 "어디를 고치는 중인지"가 분명해요
- 편집 탭을 **내용 / 배치·표시 / 참고·인계 / 검수**로 나눈 것이 좋아요. 기획자가 하는 일 순서와 맞아요
- **구좌 유형 변경 창**이 미리보기 그림과 "기존 문구·메모·레퍼런스는 유지돼요" 안내를 함께 보여 줘서 바꾸기 전에 불안하지 않아요
- **전체 검수**(누락 n개)를 버튼 하나로 모은 것
- 가운데에서 요소를 누르면 오른쪽 해당 입력칸으로 이동·강조되는 것

### 1-2. 고치면 좋을 것 (중요한 순)

| # | 지금 | 문제 | 제안 |
|---|---|---|---|
| 1 | 821~1100px 폭에서 오른쪽 편집 패널이 화면 밖으로 잘림 | 노트북 화면 확대·창 반만 띄울 때 편집을 못 함 (버그) | 이 폭에서 목록 180px · 패널 280~300px로 줄이고 가운데 미리보기가 남는 폭을 씀. 폰 틀은 이미 `max-width:100%`라 줄어듦 |
| 2 | 도구 줄(검수·실행 취소·내보내기) + 노란 안내 띠가 두 줄 (약 90px) | 편집 영역이 그만큼 아래로 밀림. 노란색은 앱에서 '주의' 색인데 일반 안내에 쓰임 | 한 줄로: 왼쪽 상태 요지 한 줄 + [자세히], 오른쪽 도구. 오류(상품 못 불러옴·저장 실패)만 빨간 상자로 전부 보이기 |
| 3 | PAGE OUTLINE · LIVE WIREFRAME · SECTION INSPECTOR · SECTION CATALOG · 340px 영문 대문자 꼬리표 | 앱의 다른 화면에는 없는 말투. 제목 위 작은 꼬리표는 읽을 정보가 없음 | 꼬리표 빼고 제목만. 구좌 순서(3/6)는 편집 패널 제목 옆에 작게 |
| 4 | 가운데 큰 기획안 제목("수능 기획") | 상단 바에 같은 이름이 있음 | 빼고 "구좌를 누르면 오른쪽에서 편집해요" 한 줄만 |
| 5 | 구좌마다 아래 줄에 ↑ ↓ 복제 삭제가 늘 보임 | 항목 하나가 101px라 6개만 넣어도 목록이 화면을 넘김. 삭제 아이콘이 늘 눈에 띔 | 고른 구좌에만 아래 줄로 보이고, 나머지는 마우스를 올릴 때 항목 위에 겹쳐 뜸 (항목 68px). 터치 화면은 지금처럼 늘 보임 |
| 6 | "현재 구좌 전체의 기본 설정을 편집합니다." 회색 상자가 늘 있음 | 기본 상태에서는 당연한 말이라 매번 읽게 됨 | 요소 하나를 골랐을 때만 "선택한 요소 1개에만 적용돼요" 보이기 |
| 7 | 실행 취소·다시 실행이 글자 버튼, 기존 편집기는 아이콘+글자 | 두 편집기를 오갈 때 같은 기능이 다르게 보임 | 기존 편집기와 같은 모양으로 맞추기 |

### 1-3. 세부 구좌 구성 (유형 22개)

전체적으로 오설록몰 프로모션에서 쓰는 구좌는 다 들어 있어요. 다만 이름과 묶음을 조금 정리하면 고르기가 빨라질 것 같아요.

| # | 지금 | 제안 |
|---|---|---|
| 1 | '안내·이야기'에 11개가 몰려 있음 (메인 비주얼부터 유의사항까지) | **안내**(혜택 총정리·포장·서비스·배송·일정·유의사항·텍스트와 버튼)와 **이야기**(메인 비주얼·스토리·상품 상세·좌우 분할)로 나누기 |
| 2 | '날짜별 특가' | 앱 전체(일정표·상품·할인·미리보기)에서는 **하루특가**라고 불러요. 이름을 맞추면 상품·할인의 하루특가 행과 연결이 바로 읽혀요 |
| 3 | '카운트다운'(안내)과 '날짜별 특가'(상품)가 둘 다 마감 시각을 보여 줌 | 카운트다운을 하루특가의 표시 옵션으로 합치거나, 설명에 차이를 적기 |
| 4 | '쿠폰 받기'(이벤트)와 '혜택 총정리'(안내)가 겹침 | 혜택 총정리 안에 "쿠폰 발급 버튼" 요소로 넣는 방식도 검토 |
| 5 | 기존 기획안의 '말차 순위', '2+1' 구좌가 '3열 상품'으로 들어옴 | **순위(랭킹)**, **묶음·세트(n+1)** 유형이 있으면 좋겠어요. 상품·할인에 '묶음(조합)' 탭이 이미 있어 연결할 수 있어요 |
| 6 | 이벤트 유형(퀴즈·룰렛·스탬프·인증) | 기획 화면은 그릴 수 있지만 자사몰에서 실제 동작은 개발 협의가 필요해요. 유형 설명에 "개발 협의 필요" 표시가 있으면 기획자가 미리 알 수 있어요 |
| 7 | 처음 열 때 기존 편집기 구좌를 이름만 보고 가장 가까운 유형으로 바꿈 | 바뀐 유형을 목록에 한 번 표시(예: "2열 상품으로 가져옴")해 주면 확인하기 쉬워요 |

### 1-4. 정해야 할 것
- **두 편집기의 저장이 따로예요.** 신규 편집기에서 고친 내용은 기존 편집기·04 미리보기·내보내기에 안 나가요. 시험이 끝나면 어느 쪽을 기준으로 할지, 아니면 신규 편집기 값을 미리보기로 넘길지 정해야 해요.

## 2. 상단 바 한 줄 (반영함)

**전:** 윗줄(로고·홈/레퍼런스·새 버전 안내·예전 화면·설정) + 기획안 막대(이름·단계·상품·할인·저장·이전/다음) = 두 줄, 약 125px

**지금 (기획안 화면 6개: 브리프·구좌 구성·구좌 편집·신규 편집기·미리보기·상품·할인):**

```
[a] ‹ 기획안 이름  [01 브리프 | 02 구좌 구성 | 03 구좌 편집 | 04 미리보기·내보내기]  [상품·할인]  저장됨 07:30 ─── (●) [←] [다음: ○○ →] [📖] [⚙]
```

- 한 줄 64px. 편집 영역이 약 60px 위로 올라와요
- 홈으로 가는 길: 로고 `a`, 기획안 이름 앞 `‹`
- 레퍼런스: 책 아이콘 (마우스를 올리면 이름)
- 이전 단계: 화살표 아이콘 (마우스를 올리면 "이전: ○○". 단계 막대가 순서를 보여 줘서 글자는 줄임)
- 데이터 출처: 1600px 미만에서는 점만 (누르면 원래 안내 창)
- '예전 화면' 링크와 '새 버전 · 시험 중' 문구는 홈·레퍼런스·설정 화면에만 남김
- 1400px 미만: 단계 막대만 둘째 줄로 내려감. 720px 이하: 막대 고정을 풀어 화면을 덜 가림
- 홈·레퍼런스·설정은 원래 한 줄이라 그대로

**바뀐 파일:** `v2/brief·compose·deals·editor·editor-next·preview.html`(머리 부분), `v2/shell.css`, `v2/shell.js`
- 클래스는 `.v2top.v2one`. 예전 `.v2plan`을 보던 규칙(화면 안 다음 버튼 숨김, `[다음]` 대신 누르기, 머리 높이 `--v2-head-h`)은 둘 다 보도록 고침
- 신규 편집기(`editor-next.html`)도 같은 머리를 써요. 편집기 안쪽(도구 줄·노란 띠·꼬리표)은 원본 그대로예요

**확인:**
- 1920·1440: 한 줄
- 1280·900: 두 줄
- 390: 가로 스크롤 없음
- 7개 화면 콘솔 오류 없음
