# 23 새 버전(v2)을 앱에 붙이기 (2026-11-07)

[사용자] 업무 과정대로 화면을 다 만들었으니 새 버전을 앱에 붙이자. 예전 화면은 건드리지 않는다.

## 1. 어떻게 붙였나 [사실]
- 주소: **http://127.0.0.1:9751/v2/** (홈). 예전 화면은 `/` 그대로이고, 새 버전 윗줄의 [예전 화면]으로 오갈 수 있다.
- 화면 8개: `home`, `brief`, `compose`, `editor`, `preview`, `deals`, `library`, `settings`. 비교(26)·검색창(27) 목업은 디자인 참고라 넣지 않았다.
- 앱 보안 머리(CSP `script-src 'self'; style-src 'self'`) 때문에 목업 안의 `<style>`·`<script>`를 `static/v2/<화면>.css`·`.js` 파일로 나눴다. 토큰은 예전 화면과 같은 방식(`<meta name="planner-token">`)이다.
- 공통 틀(plans/20 §4-11):
  - 윗줄: 홈 · 레퍼런스 · ⚙, 예전 화면 링크
  - 기획안 막대: 01~04 단계, [상품·할인], [다음 →], [목록으로]
  - 파일: `static/v2/shell.css`·`shell.js`. 서버 호출은 `static/v2/api.js`
- 서버(`server.py`)에 더한 것은 두 가지:
  - `/v2/{화면}`: 정해진 이름만 열고, 나머지는 404
  - `GET /api/connections`: 키는 있음/없음만, 사용량은 `usage.summary()`
  - 예전 라우트와 파일은 그대로다.
- **이제 원본은 `static/v2`이다.** `plans/mockups`의 20~29는 디자인 기록으로 남긴다. 옮기는 데 쓴 스크립트는 한 번만 썼다.

## 2. 실제 데이터 / 아직 예시
| 화면 | 실제 | 아직 예시 |
|---|---|---|
| 홈 | [시작] → 고른 명분·씨앗을 브리프 중심 키워드로 넘김. [이어서 하기] → 브리프 | 일정표·이벤트·기획안 목록·명분 사전·실적 한 줄 |
| 브리프 | 근거 패널의 **검색**(네이버 검색어 트렌드: 오르는 중/줄어드는 중/꾸준, 가장 많이 찾는 달, 최근 4주 지수)과 **글**(네이버 뉴스·블로그, 관련 높은 순, 원문 새 탭). 중심 키워드에도 실제 근거. 연결 상태 한 줄 | 마인드맵 가지(검색광고 키가 오면 연관 키워드로), 우리 데이터, 메인 카피 제안, 느낌 레퍼런스 |
| 설정·데이터 | 외부 연결의 네이버 카드 3개 상태·오늘/이번 달 사용량, [연결 확인] 실제 호출('차', 검색 2·트렌드 1회) | 데이터 상태, 원가 파일, 사전과 목록 저장, 기획 기준 값 |
| 구좌 구성·구좌 편집·미리보기·상품·할인·레퍼런스 | - | 전부 예시 (목업 그대로) |

- 바깥으로 보내는 것은 키워드뿐이다. 브리프는 키워드를 **눌러 근거를 볼 때만** 부르고, 같은 키워드는 화면에서 한 번, 서버에서 6시간 캐시한다.

## 3. 다음에 붙일 순서 [제안]
1. **기획안 저장 하나로 화면을 잇기**: 홈 [시작] → 기획안 생성 → 브리프·구성·편집·상품·할인이 같은 기획안을 읽고 쓰기. 예전 `/api/am/*` 기획안 저장을 다시 쓸 수 있는지 먼저 본다.
2. **홈 실데이터**: 몰 이벤트 목록·예정 행사(timeline)·명분 사전(settings/명분사전.csv)·SAP 실적 한 줄
3. **상품·할인 실데이터**: `/api/products`·`/api/product/{seq}`(상품 상세 서랍), 판정·원가율은 engine 그대로
4. **설정·데이터 실데이터**: 데이터 상태(`/api/meta`·`/api/rebuild`), 사전과 목록 저장(이미 있는 `/api/settings/*` + 새로 필요한 것)
5. 구좌 구성·편집·미리보기·레퍼런스는 1번이 붙은 뒤에

## 4. 점검한 것
- 8개 화면 200. CSP 머리 있음. 화면이 부르는 css·js가 모두 열림. 화면 사이 링크는 `/v2/` 안에서만. 이상한 주소(`/v2/index`, `/v2/home.html` 등)는 404.
- `/api/connections`: 토큰 없으면 401. 응답에 `.env`의 키 값이 들어 있지 않음.
- 브리프 실데이터 표시 함수(오르는 중·가장 많이 찾는 달·링크 새 탭·이스케이프·키 없음/한도 문구·같은 키워드 한 번만 부르기) 단위 점검.
- 화면 모양은 사람이 직접 본다 (자동 브라우저 시험은 하지 않음).
