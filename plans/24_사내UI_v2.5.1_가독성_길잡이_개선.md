## 2. 확인한 것 (`sub` + 이 변경, 샘플 데이터, 포트 9741)
- `/v2/` 8개 화면 콘솔 오류 0, 화면 사이 이동·저장·불러오기·검증·PROMO_WORK 엑셀 내보내기
- 브리프 → 구성 → 편집 → 미리보기를 [다음] 하나로 같은 기획안(id)을 따라 이동

- JS 동작(데이터 바인딩·이벤트 이름·저장 형식)은 바꾸지 않음. 바뀐 JS: `shell.js`(공통 UI), `plan.js`(진행 상황·제목), `editor.js`(후기 나중 채우기·좁은 화면), `home.js`(명분 배치), `preview.js`(확인할 것 묶기)
