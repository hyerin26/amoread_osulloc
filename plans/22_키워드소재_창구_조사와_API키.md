# 22 키워드 소재 창구 — 조사, 검색어 묶음, API 키 받는 법 (2026-11-07)

관련: plans/20 §3(키워드 소재 후보), plans/21(핀터레스트), plans/16 §2.6(엔지니어 검증 K1~K7)

## 1. 검색어 묶음(미리 정해 둔 검색어) [사용자 → 제안]
[사용자] 미리 정해 둔 검색어가 있고 그 필터를 고르면 그 검색어들로 검색한 결과가 한곳에 모여 보이면 어떨까?

- **네이버 창구(검색광고·데이터랩·뉴스·블로그): 된다.**
  - 이미 있는 '트렌드 키워드 그룹'(`settings/트렌드키워드.csv`, 화면 ⚙에서 고침)을 그대로 **검색어 묶음**으로 쓴다. 새 설정을 만들지 않는다.
  - 예) 묶음 '설 선물' = 설 선물 · 명절 선물세트 · 설 선물 추천. 이 묶음을 고르면 세 검색어의 연관 키워드, 검색 추이, 최신 글이 합쳐져 한 화면에 나온다.
  - 쓰는 곳은 브리프 키워드 확장(씨앗 대신 묶음 고르기)과 레퍼런스 라이브러리의 필터.
- **핀터레스트: 검색 결과를 그대로 모아 오는 건 안 된다.**
  - [사실] 공식 API의 핀 검색은 **내 계정의 핀만** 찾는다.
  - 아무 핀이나 검색어로 찾는 '파트너 핀 검색'은 베타라 일부 앱에만 열려 있고, 검색어당 상위 10개뿐이다.
  - 검색 결과 화면을 긁어 오는 것은 약관 위반 소지가 있어서 하지 않는다.
  - [제안] 그래서 이렇게 한다:
    - (가) 구독한 공개 보드(plans/21 §7 A안)에서 들어온 핀을 **검색어 묶음으로 거른다**. 핀 제목·설명·보드 이름에 묶음의 검색어가 들어간 것만 보여준다.
    - (나) 묶음마다 [핀터레스트에서 이 검색어로 보기]를 두어 새 탭으로 바로 연다(가져오지는 않음). 마음에 드는 건 캡처해 붙여 넣는다(B안).
    - (다) 파트너 핀 검색 베타는 엔지니어가 신청해 보고, 열리면 묶음 검색어당 상위 10개를 받아 온다.

## 3. API 키 받는 법
### 3-1. 네이버 개발자센터 (데이터랩·검색, 쇼핑인사이트까지 한 키)
1. developers.naver.com → 로그인 → **Application › 애플리케이션 등록**
2. 사용 API에 **검색**, **데이터랩(검색어트렌드)**, (나중에) **데이터랩(쇼핑인사이트)** 를 추가
3. 비로그인 오픈 API 서비스 환경: **WEB 설정**, 주소는 `http://127.0.0.1` (이 PC에서만 씀)
4. 등록하면 나오는 **Client ID**, **Client Secret**을 아래 .env에 적는다

### 3-2. 네이버 검색광고 (연관 키워드·검색수)
1. searchad.naver.com → 검색광고 계정으로 로그인 (회사 광고계정을 쓸지 담당자 계정을 쓸지는 plans/16 K1)
2. **도구 › API 사용 관리** → 약관 동의 → 발급
3. 나오는 **액세스 라이선스**, **비밀키**, 그리고 **CUSTOMER_ID(광고계정 번호)** 를 아래 .env에 적는다
4. PC 시각이 몇 분 이상 틀리면 거절(403)되니 윈도우 시간 자동 맞춤을 켜 둔다

### 3-3. 어디에 넣나: `.env` 파일
- 위치: **`C:\Users\amore\.claude\amoread_redesign\workspace\amoread_app\.env`** (run_redesign.bat이 여는 사본. main 사본을 쓸 때는 `C:\Users\amore\.claude\amoread\workspace\amoread_app\.env`)
- 같은 폴더의 **`.env.example`을 복사해 이름을 `.env`로 바꾸고** `=` 뒤에 값을 붙여 넣는다. 저장한 뒤 서버를 다시 켜면 반영된다.
- 규칙 (보안 개발 가이드: 하드코딩 금지)
  - 키는 `.env`에만 둔다. 코드·문서·채팅·메신저·목업 공유 ZIP에 넣지 않는다.
  - `.env`는 git에서 빠져 있다(`.gitignore`). 커밋되지 않는다.
  - 키가 새어 나갔다고 생각되면 개발자센터·검색광고에서 바로 재발급한다.
- 확인: 키가 없는 창구는 화면·응답에 '연결 안 됨(no_key)'으로 나온다. 키를 넣은 뒤에도 '오류'면 메시지를 보고, 키 값은 남에게 보내지 말고 엔지니어에게 화면만 보여 준다.
