# 신규 구좌편집기 UX 재배치 — 요소별 근거 (2026-11-15)

- **대상:** `/v2/editor-next` (기존 구좌 편집 → [신규 편집기로 열기 (시험)])
- **원칙:**
  - 기능·저장 형식은 그대로 (구좌 추가·삭제·복제·순서, 유형 변경, 요소 추가, 상품·후기·레퍼런스 연결, 검수, 실행 취소, JSON·HTML 내보내기)
  - 바꾼 것은 위치·크기·간격·문구·보이는 때뿐이에요
- **참고:**
  - Figma UI3 — 왼쪽 레이어, 가운데 캔버스, 오른쪽 속성. 패널은 1px 선으로 나뉘고, 오른쪽 위 탭이 1단 탐색
  - Relume 와이어프레임 — 구좌 목록 행에 마우스를 올리면 행 동작이 뜨고, 캔버스 위에 페이지 도구
  - 앱의 Green UI v2.5.1 토큰. 새 색·크기 값은 만들지 않았어요
- **스킬:** impeccable(작업 화면 = Operate 모드, craft floor), ui-ux-pro-max 점검 항목

---

## 0. 사용자와 목표

**누가:** 오설록몰 프로모션 기획자. 사무실 노트북(1280~1920)에서 기획안 하나를 30분~1시간 다듬어요.

**이 화면에서 하는 일 (빈도순):**
1. 구좌를 하나씩 골라 문구 쓰기 → 상품 연결 → 다음 구좌
2. 구좌 순서 바꾸기·추가·복제·삭제
3. 빠진 것 확인(검수) → 그 구좌로 가서 고치기
4. 디자이너에게 넘길 파일 내보내기

**성공:** 6~10개 구좌를 고치는 동안 화면을 옮기거나 스크롤로 도구를 찾지 않고, 지금 무엇을 고치는지 늘 알아요.

## 7. 확인

- **기능** (브라우저에서 직접): 구좌 추가 → 삭제 → 순서 바꾸기 → 실행 취소, 내보내기 메뉴(고르면 닫힘), 검수 창 → 구좌 이동, 요소 추가·선택, 유형 변경 창. 결과가 전과 같음
- **오류:** 신규 편집기(실제·예시)·기존 편집기·브리프 콘솔 오류 없음
- **e2e** (`tests/e2e/test_editor_next.py`): 내보내기가 메뉴 안으로 들어가서 3번 테스트의 모양 확인 3줄을 새 구조에 맞춤 (검수 버튼 36px, 메뉴 안 내보내기 2개, 밑줄 탭, 1px 선, 세 칸 첫 줄 높이 같음). 이 PC엔 Playwright가 없어 같은 값을 브라우저에서 확인

## 8. 남은 것·정할 것

- 미리보기의 구좌를 고르면 그 자리에 떠 있는 작은 도구(위·아래·복제·삭제)를 두는 것 (Relume 방식) — 기능 추가라 이번엔 안 함
- 기존 기획안에서 가져온 상품 구좌는 상품이 비어 있어요(검수 5건). 가져오기 때 상품 칸도 옮길지 결정 필요 (기능 변경)
- 두 편집기 저장 분리 (plans/26 1-4)
- 편집기 원본(`amoread_editor/editor/v1.12`)에서는 문구만 고쳤고 나머지는 앱 쪽 `editor-next-ux.css`로 덮었어요. 원본 담당자가 v1.12를 더 고치면 이 파일과 겹치는지 확인이 필요해요
