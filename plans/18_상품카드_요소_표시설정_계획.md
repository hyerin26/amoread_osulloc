## 2. 난이도 판단

어렵지 않다. 다만 두 군데를 조심해야 한다.

| 부분 | 난이도 | 이유 |
|---|---|---|
| 요소 켜고 끄기 (구좌 단위) | 쉬움 | `price_display` 5가지를 요소 스위치 묶음으로 바꾸고, 5가지는 '빠른 설정'으로 남김 |
| 순서 바꾸기 (구좌 단위) | 쉬움~보통 | 이미 있는 `sortable.js`(끌기, Alt+↑/↓)를 편집 패널의 요소 목록에 그대로 씀 |
| 카드 하나만 다르게 | 보통 | 카드별 예외를 두면 데이터·화면이 복잡해짐 → 켜고 끄기만 카드별 예외 허용, 순서는 구좌 단위만 [제안] |
| 문구 알약 '며칠 뒤면 n원 비싸져요' | **조심** | 가격 주장이라 틀리면 허위 표시가 됨. 계산 규칙과 확인이 필요(3장) |
| 저장 | 조심 | 서버 필드 추가 필요(통합 세션·엔지니어). 서버가 받기 전까지는 저장이 안 되므로 순서상 먼저 요청 |

→ **R6(04 구좌 편집)에서 같이 하는 게 맞다.** 카드를 실제로 보면서 고치는 곳이 04이고, 04 편집 패널에 '표시' 탭이 들어갈 자리가 있다. 02에는 지금처럼 빠른 설정만 둔다.

빠른 설정(지금 5가지)은 위 스위치를 한 번에 맞추는 버튼으로 남긴다. 예: '이미지·상품명만' = 가격 3개 끔.

### 문구 알약 종류와 계산 규칙

| 종류 | 예 | 계산 | 켤 수 있는 조건 |
|---|---|---|---|
| 가격 오름 예고 | 3일 뒤면 4,800원 비싸져요 | 일수 = 행사 종료일 − 미리보기 날짜, 금액 = 정가 − 판매가 | 이 기획안 안에서 종료 다음 날 같은 상품 행사가 이어지지 않을 때만. 이어지면 알약을 끄고 이유를 보여 줌 |
| 하루특가 | 오늘만 40% | 하루특가 날짜 = 미리보기 날짜 | 하루특가 행 |
| 남은 기간 | 11/30까지 | 행사 종료일 | 항상 |
| 직접 쓰기 | (자유) | 없음 | 항상. 가격·기간 숫자가 들어가면 '숫자를 확인해 주세요' 표시 |

#### '가격 오름 예고'의 행사 뒤 판매가 (사용자 결정 2026-11-06: 불러올 수 있으면 자동, 아니면 직접)

행사 종료 다음 날의 판매가를 아래 순서로 찾는다. 찾은 근거를 알약 옆에 작게 보여 준다.

| 순서 | 근거 | 다음 날 판매가 | 데이터 [사실] |
|---|---|---|---|
| 1 | 이 기획안에 다음 날 같은 상품 행사가 있음 | 그 행사 할인가 | 03 상품·혜택 행(시작·종료·할인율) |
| 2 | PROMO_WORK에 다음 날 같은 상품 행사가 이미 잡혀 있음 | 그 행사 할인가 | '같은 기간 이미 잡힌 행사'에 쓰는 PROMO_WORK 자료 |
| 3 | 둘 다 없음 | 정가 | 상품 자료의 정가(원가 시트) |
| - | 정가가 없거나, 다음 날 가격이 지금과 같거나 더 쌈 | 자동 안 함 → 직접 쓰기, 또는 알약 끔 | |

- [가설] '행사가 없으면 정가로 판다'는 전제는 담당자 확인이 필요(멤버십가·다른 채널 가격 등 예외가 있는지). 확인 전에는 3번 근거일 때 '정가 기준' 표시를 붙인다.
- 담당자는 자동값을 언제든 직접 고칠 수 있고, 고친 카드는 '직접 씀'으로 표시한다.
- 이 기획안 행을 바꾸면 알약 값도 다시 계산한다. 기획안을 03에서 저장하지 않은 상태면 저장한 값 기준으로 계산한다.

- 문구 틀은 바꿀 수 있게 한다(예: '{일}일 뒤면 {금액}원 비싸져요' → '{일}일 남았어요 · {금액}원 아껴요'). 계산값만 자동이고 말투는 담당자가 고른다.
- 미리보기 날짜는 04 하루특가 날짜 선택(이미 있음)을 함께 쓴다.

## 4. 화면 예시 (04 편집 패널 '표시' 탭)

```
상품 카드 표시                     빠른 설정 [할인율 강조] [가격 표시] [이미지·상품명만] [섹션 대표 가격]
⋮⋮ [✓] 이미지
⋮⋮ [✓] 상품명
⋮⋮ [✓] 할인율   ─┐ 한 줄로
⋮⋮ [✓] 판매가   ─┘
⋮⋮ [ ] 정가
⋮⋮ [✓] 문구 알약   종류 (가격 오름 예고)  틀 [ {일}일 뒤면 {금액}원 비싸져요 ]
⋮⋮ [✓] 카드 문구
이 구좌의 카드 6개에 모두 적용돼요. 카드 하나만 끄려면 캔버스에서 카드를 누르세요.
```

- '한 줄로'(할인율 + 판매가를 같은 줄에)는 디자이너 카드 모양에 있으면 넣고, 없으면 뺀다.
- 캔버스 카드를 누르면 그 카드만의 켜고 끄기(예외)와 알약 문구 고치기.

## 5. 데이터 [제안]

```
Section.card = { order: ['img','name','rate','sale','list','pill','copy'], on: { img: true, ... }, pill: { kind: 'up', tpl: '{일}일 뒤면 {금액}원 비싸져요' } }
Slot.cardOff = ['pill']          // 이 카드만 끈 요소
Slot.pillText = ''               // 이 카드만 고친 알약 문구 (비면 틀로 계산)
```

- `price_display`는 지우지 않는다(05 문서·예전 기획안 호환). `card`가 없으면 `price_display`로 기본값을 만든다.
- 서버 `api.py`에 위 필드 추가 요청(통합 세션). 탭 구좌(plans/17 2-1)의 `tabs`도 같은 때 함께 요청한다.
