# 진행 기록: v0.2 2차 (하루특가 편성과 페이지 연결) 2026-11-06

## 범위
하루특가 편성표, 하루특가 섹션 연결(R1~R6), 캘린더 날짜 상세의 기획안별 편성(R2, R3), 날짜 없는 하루특가 담기의 후보 목록화(R9).

## 데이터
- 하루특가 행은 그대로: 상품 하나 = 날짜 하루 = 하루특가 행 하나. **같은 날짜 안의 행 순서 = 자리 순서.** PROMO_WORK 엑셀, 기존 검증 그대로
- 기획안에 `deal_plan` 추가: `{ slots: 하루 자리 수(1~12, 기본 4), candidates: [{ seq 또는 items, rate, memo }] (100개까지) }`. ② 상품·할인에 속하므로 수동 저장
- 서버: `api.DealPlan` 모델, `store.save`에 저장, `/api/am/calendar` 기획안마다 `deal_days`(날짜별 하루특가 수), 새 `GET /api/am/day?date=` (그날에 걸친 기획안, 하루특가 섹션 여부, 자리 수, 그날 하루특가)

## 바꾼 것
| 영역 | 내용 | 파일 |
|---|---|---|
| ② 상품·할인 | `할인 행` / `하루특가 편성` 두 보기. 같은 편집 중인 표를 고침. 저장하지 않은 변경 판단에 하루특가 설정 포함 | `am/hub.js` |
| 하루특가 편성 | 날짜(기획안 기간) × 자리 격자. 빈 칸 → 후보(걸리는 점 표시) 또는 상품 검색으로 넣기. 채운 칸 → 할인율 바꾸기, 다른 상품으로, 빼기. 자리 수 고르기. 기간 밖 하루특가 안내 | `am/deals.js` |
| 후보 상품 | 상품 검색으로 추가, 후보별 할인율, 이 기획안에서 쓴 횟수·날짜, `추천 후보 가져오기`(가장 가까운 날의 기존 하루특가 후보) | `am/deals.js` |
| 빈 자리 채우기 | 오늘 이후 날짜의 빈 자리를 후보로 채움. 같은 날 중복, 같은 상품 14일 안 재특가(이 기획안과 잡힌 행사 모두), 최근 하루특가 14일 안을 피함. 적게 쓴 후보부터 | `am/deals.js` |
| R1 | 하루특가가 있는데 하루특가 섹션 없음 → `[섹션 추가]` (1차와 같음) | `am/next.js` |
| R4 | 하루특가 섹션 삭제 시 "하루특가 N개는 상품·할인에 남아요" | `am/page.js` |
| R5 | 하루특가가 기획안 기간 밖 → 다음에 할 일, 누르면 하루특가 편성 | `am/next.js` |
| R6 | 하루특가 섹션이 있는데 앞으로의 날짜에 빈 자리 → "하루특가 빈 자리 N개" 누르면 하루특가 편성 | `am/next.js` |
| ③ 하루특가 섹션 | 날짜마다 채운 자리/하루 자리 수, 빈 자리 수, `하루특가 편성 열기` | `am/page.js` |
| R2 담기 | 날짜를 아는 하루특가 담기(캘린더 후보 등): 그날 기획안 1개면 바로, 여러 개면 "어느 프로모션에 노출할까요?"(하루특가 섹션 있는 것 먼저, 그날 채운 자리 표시), 없으면 기획안 고르기 또는 새 기획안. 알림 `[보기] [되돌리기] [다른 기획안에 담기]`, 자리가 찼거나 섹션이 없으면 알림에 표시. 작업 중이 아닌 기획안에도 바로 저장 | `am/intake.js` |
| R9 담기 | 날짜 없는 `하루특가로 담기`(상품 상세 등): 작업 중 기획안의 하루특가 후보로. ②가 열려 있으면 편집 중인 후보에 | `am/intake.js`, `am/hub.js` |
| R3 캘린더 | 날짜 칸의 `+기획 N`이 내 기획안들의 그날 하루특가 수. 날짜 상세에 "이 날의 내 기획안" (기간, 하루특가 채운 자리/자리 수 또는 섹션 없음, 그날 상품, `편성 보기`) | `calendar.js` |
| 문구 | 날짜 상세의 "하루특가 — PROMO_WORK"를 "하루특가: PROMO_WORK에 잡힌 N개"로 | `calendar.js` |

## 알려진 한계
- 같은 날짜 안 자리 순서를 끌어서 바꾸는 기능은 없음 (빼고 다시 넣어야 함)
- 빈 자리 채우기는 오늘 이전 날짜는 건드리지 않음
- 잡힌 행사(PROMO_WORK)의 하루특가와 겹침은 상품의 '예정 행사' 정보 기준. 이 기획안을 PROMO_WORK에 붙여넣은 뒤에는 자기 자신과 겹친다고 표시될 수 있음 (상태 '반영됨' 처리 때 함께 정리, 4차)
- 같은 상품을 같은 날 여러 프로모션에 함께 노출하는 경우(인터뷰 A11)는 아직 지원하지 않음
