## 컬러·라운드·선택

기본 텍스트와 주요 행동 #141414, 본문 보조 #666666, 표면 #FFFFFF/#F3F3F3, 기본 경계 #DEDEDE. UI·예시 그래픽을 무채색으로 정리했다. leaf/green/blue 등 과거 CSS 토큰 이름은 호환용 별칭으로만 남기며 값은 회색이다. 기존 변수 이름을 이유로 새로운 초록색을 추가하지 않는다.

- 조작 요소 8px: 버튼, 필드, 탭, 배지, 접는 영역, 이미지 프레임.
- 내용 컨테이너 12px: 카드, 폰 프레임, 큰 패널, 확인창.
- 구좌 경계·전체 폭 이미지는 0px. 상태 점·브라우저 기본 폼 표시의 고유 형태는 장식적 라운드와 구분한다.
- 입력 포커스는 1px 테두리 색만 #707070으로 바꾼다. 외곽 링/그림자 없음.
- 키보드 버튼 초점은 1px 회색 선, offset2px. 구좌 선택은 rgba(20,20,20,.28) 1px. 요소·카드는 1px 회색. 미적용 후보는 1px 점선+임시 미리보기 문구.
- 선택/포커스가 내용의 폭·높이를 바꾸지 않는다.

한글 Pretendard, 영문·숫자 Inter, 400/500/600/700 굵기는 유지한다. 폰트와 라이선스는 앱/가이드/공유 HTML에 계속 내장한다.

## 레퍼런스 단위와 크게 보기

라이브러리의 ‘섹션별 사례’는 프로모션의 구좌 1개, ‘전체 프로모션’은 여러 섹션의 순서와 흐름이다. 카드에 단위·소속 프로모션·가져올 수 있는 범위를 표시한다. 세로형 카드(4:5)가 기존 144px 그림보다 큰 배치를 보여주며, 열면 별도 큰 보기에서 선택한 섹션/전체 프로모션을 전환한다. 전체 페이지는 내부에서 세로 스크롤한다. 전체 흐름 안의 등록 섹션으로 다시 이동할 수 있다.

‘AI 기획’의 관련 레퍼런스와 S06의 검색/상세에서도 같은 구성 미리보기를 사용한다. 앱의 레퍼런스는 현재 모두 예시 데이터다. **실제 캠페인 이미지를 수집하거나 새로 연결한 것은 아니며**, 전체 보기도 원래 CAMPAIGN_SECTIONS의 구성을 표현한 예시다. 자료 원본을 확보하면 같은 긴 프레임에 실제 이미지를 연결하는 작업이 필요하다. 실제 이미지·성과를 임의로 만들어 출처로 제시하지 않는다.

| 표시 | 의미 |
|---|---|
| 배치 복사 가능 | 준비된 편집용 레이아웃으로 구좌 구성을 바꿀 수 있다. 기존 구좌의 카피·연결 상품·메모·기획안 가격을 보존한다. 슬롯보다 많은 상품은 기존 미배치 계약을 따른다. |
| 참고자료만 첨부 | 디자인 요청에 자료를 연결할 수 있다. 편집 가능한 배치가 없어 바로 적용하지 않는다. |

큰 보기의 ‘구좌 편집에서 사용하기’는 편집 패널의 기존 상세로 이동한다. 탐색·확대·범위 전환·전체 캠페인 열람으로는 기획안을 바꾸지 않는다. 구좌의 실제 변경은 패널의 배치 적용 또는 첨부 버튼에서만 일어난다.

## 가격 연결 패널

기존의 가격 변수 태그 행을 ‘문구에 가격 연결하기’ 접이식 영역으로 바꿨다. 넣을 위치(메인/서브 카피/버튼 문구)와 가격 정보(행사 판매가·정가·할인율·할인액·종료 후 차액)를 선택하고 현재 값을 확인한 뒤 넣는다. 마지막으로 포커스한 문구와 위치 선택을 동기화한다. 접기/펼치기와 값 선택에도 상태를 유지한다.

내부 토큰 문법 `{행사판매가}` 등과 첫 번째 연결 상품 기준 계산은 그대로다. 문구 삽입은 기존 일반 편집의 Undo/Redo에 포함한다. 새 토큰 스키마나 실제 판매 가격 변경 기능은 추가하지 않는다.

## 소스와 빌드

- `design/tokens_v2.3.*`: 현재 토큰. v0.2/v2.1/v2.2는 이력 보존.
- `src/styles.css`, `src/theme.css`: 기존 호환 레이아웃의 문자색/라운드도 무채색·역할 값으로 정리.
- `src/monochrome.css`: 현재 포커스·선택·레퍼런스·가격 연결 UI.
- `src/references.js`: 데이터 수정 없이 레퍼런스 카드/구성 예시/크게 보기를 그린다.
- `src/app.js`: 기존 업무 상태와 행동, 라이브러리·확대 보기 연결.
- `scripts/build.py`: 폰트→토큰→기존 스타일→새 스타일, references.js→app.js를 단일 HTML에 합친다. 가이드는 현재 v2.3로 생성한다.

`python3 scripts/build.py --check`, `node --check src/app.js`, `node --check src/references.js`로 확인한다. 예전 v2.2 가이드 HTML은 이전 시각안 스냅샷으로 보존한다.
