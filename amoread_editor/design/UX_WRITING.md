# AMOREAD UX 라이팅 원칙

D-048 / CR-20261105-003 · 2026-11-05.

사용자가 제공한 앱인토스 UI/UX 가이드 중 **UX 라이팅** 절의 원칙만 적용한다. 브랜드·탭바·그래픽·입점 정책을 AMOREAD 요구사항으로 채택한 것은 아니다. 기존 Tea Green, Pretendard/Inter, 편집·가격·저장·공유 기능은 유지한다.

## 기본 원칙

1. 안내·오류·완료 문장은 해요체로 쓴다. 짧고 친근하되 업무 도구에 맞는 정확성을 유지한다.
2. 누가 무엇을 하는지 드러나는 능동형을 우선한다. 결과·안심을 더 정확하게 전달한다면 ‘실제 판매 가격은 바뀌지 않아요’처럼 부정형·수동형도 쓴다.
3. 막혔다는 설명에서 끝내지 않고 다음에 할 수 있는 일을 알려준다. 단, 불가능한 동작이나 실제 AI·사내 데이터 연동을 가능한 것처럼 설명하지 않는다.
4. ‘하시겠어요’, ‘확인 바랍니다’, ‘처리 완료’ 대신 자연스러운 문장과 구체적인 행동을 쓴다.
5. 명사를 이어 붙이기보다 동사로 풀어 쓴다. CTA→버튼 문구, SKU→상품 코드처럼 꼭 필요한 전문어만 남긴다. 실무 용어인 ‘구좌’와 ‘레퍼런스’는 유지한다.
6. 버튼·필드·탭·상태는 빠르게 읽도록 ‘닫기’, ‘가격 적용하기’, ‘상품 코드’처럼 짧게 쓴다. 모든 레이블을 억지로 완전한 해요체 문장으로 늘리지 않는다.
7. 오류는 잘못된 항목 가까이에서 이유와 해결 방법을 알려준다. 실제 정가를 넣어 ‘0원부터 30,000원 사이로 입력해 주세요’처럼 쓴다.
8. 확인창 왼쪽 버튼은 ‘닫기’. 닫기, 가격 되돌리기, 변경 버리기를 같은 ‘취소’로 뭉뚱그리지 않는다. 삭제·가격 버리기의 결과도 분명히 말한다.

## 행동별 뜻

| 문구 | 실제 행동 |
|---|---|
| 가격 확인창 ‘닫기’ / Escape | 화면 이동을 멈추고 입력한 가격 초안을 유지해요. |
| 가격 되돌리기 | 초안만 현재 기획안 가격으로 돌려요. |
| 변경한 가격 버리고 이동 | 초안을 버리고 원래 가려던 화면으로 이동해요. |
| 가격 적용하고 이동 | 기획안 공통 행사 가격을 확정하고 이동해요. 실제 운영계 가격은 바꾸지 않아요. |
| 레이아웃 탐색 ‘닫기’ | 임시 미리보기를 끝내고 기존 레이아웃을 유지해요. |
| 참고자료로 추가하기 | 참고자료를 구좌에 첨부해요. 레이아웃 적용은 별도예요. |
| 내보내기 확인창 ‘닫기’ | 미리보기로 돌아가요. 기획안 내용은 그대로예요. |
| 이 상태로 내보내기 | 미확정 상태를 표시한 기획안을 내보내요. |
| 검색 조건 지우기 | 검색어와 유형을 비우고 전체 예시 목록을 보여줘요. 기획안은 바꾸지 않아요. |

## 적용 예시

| 이전 | 이후 |
|---|---|
| CTA 문구 | 버튼 문구 |
| 가격 변수 삽입 | 가격 자동 입력 |
| 조건에 일치하는 상품이 없습니다. | 다른 상품명이나 카테고리로 다시 찾아보세요. |
| 현재 상태로 내보내시겠어요? | 지금 상태로 내보낼까요? |
| 미적용 가격 변경을 취소했습니다. | 적용 전 가격으로 되돌렸어요. |
| 구좌가 삭제됐습니다. Undo로 복원할 수 있어요. | 구좌를 삭제했어요. ‘실행 취소’로 되돌릴 수 있어요. |
| 독립 HTML 기획안을 내보냈습니다. | HTML 파일 다운로드를 시작했어요. |

다운로드는 시작한 시점까지만 알리며 실제 저장 완료를 단정하지 않는다. 실제 AI를 호출하지 않는 제안은 ‘미리 준비한 예시’라고 설명한다. ‘참고 전용’ 같은 상태는 오류가 아니므로 중립색으로 표시한다.

## 적용 범위와 유지보수

앱의 안내·버튼·확인창·빈 결과·가격 오류·토스트와 공유 문서의 시스템 설명에 적용한다. 사용자가 작성하거나 기존에 저장한 프로모션 카피·상품명·디자인 메모를 자동 교정하거나 덮어쓰지 않는다. 기본 예시 데이터도 보존한다.

[ux-copy.csv](ux-copy.csv)는 단순 문구 교체 기록이다. 금액·개수에 따라 달라지는 확인창/가격 오류 문구는 `src/app.js`의 `renderOverlay`, `refreshPriceUi`, `productsPanel`을 함께 확인한다.

라벨과 입력창은 for/id로 연결하고, 오류는 aria-describedby·aria-invalid로 연결한다. 확인창은 제목·설명·키보드 포커스를 제공하며 Tab 순환·Escape 닫기·닫은 뒤 포커스 복귀를 지원한다. 이 표현 개선을 이유로 기존 기능·가격 조건·저장 범위를 바꾸지 않는다.
