# AMOREAD Accent UI v2.4

D-050~052 / CR-20261105-005. [시각 가이드](visual-guide_v2.4.html), [CSS 토큰](tokens_v2.4.css), [JSON 토큰](tokens_v2.4.json).

- 바탕/텍스트: 기존 중립 흑백 유지. 포인트 #A74432, hover #923B2B, pressed #7B3225. 선택 배경 #FCF4F1, 선택선 rgba(167,68,50,.32) 1px. 주요 행동과 행사 가격에 한정해 사용.
- 수정 가격: 최초 생성/이관 시점 기준과 다르면 ‘수정됨’. 색 외 텍스트로도 구분. 정가/원가는 회색·검정. 가격 입력 초안은 옅은 배경+아직 미적용 안내.
- 컨트롤 8px / 컨테이너 12px, 한글 Pretendard / 영문·숫자 Inter, SVG 1.75 stroke 유지. 입력 포커스는 1px 테두리 변화, 글로우 없음.
- 체크박스 18px 고정 / 레이블 줄높이20px / 간격8px / 세로 중앙 정렬.
- 레이아웃 변경은 콘텐츠 탭 최상단. 편집 패널 열기/닫기는 캔버스 툴바, 작은 화면의 패널 내부 닫기만 추가.
- 홈은 문서 목록 중심: 이름/기간/구좌 수/최근 수정/이어 편집, 검색과 새 기획안. 실제 브라우저 저장 건수만 표시.
- 캔버스 손잡이 드래그는 얇은 삽입선, 버튼·키보드 대안 제공. 카피 더블클릭은 현재 폰트와 크기를 유지한 직접 입력. 요청사항은 미리보기 구좌 옆에서 편집하며 출력에는 텍스트로 표시.
- 구현: src/workspace.css + workspace.js + interactions.js + app.js. 빌드 결과 index.html과 공유 HTML에 폰트/테마 내장. 이전 v2.3 산출물 보존.
