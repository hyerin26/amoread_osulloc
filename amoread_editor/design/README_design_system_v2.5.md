밝은 그린/레드는 작은 텍스트에 쓰지 않는다. 흑백 바탕·Inter/Pretendard·컨트롤8/컨테이너12px·얇은 포커스 스트로크를 유지한다. 노랑은 기존 미확정 경고에만 제한적으로 사용한다.

문구 한 번 클릭(키보드 Enter/Space)으로 직접 입력. Enter/blur 저장, Shift+Enter 줄바꿈, Escape 취소. 캔버스는 ‘이동’ 손잡이와 위/아래 버튼을 상시 표시한다. 목록 손잡이도 같은 포인터 정렬을 사용한다. 드래그 중 구좌 이름·삽입선·소스 약한 표시를 제공하며 같은 스크롤 영역의 여백에도 놓을 수 있다. 경계 자동 스크롤·영역 밖 취소와 가격 초안 확인을 유지한다.
