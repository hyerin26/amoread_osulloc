## 폰트

한글 **Pretendard v1.3.9**, 영문·숫자 **Inter v4.1**. Inter → Pretendard 순서로 결합한다. 기기 설치 여부에 의존하지 않도록 수정하지 않은 공식 WOFF2와 OFL 라이선스를 `assets/fonts/`에 포함했다. 앱·가이드·공유 HTML에는 폰트를 내장한다. 네트워크 요청 없이 열리며 단일 HTML 용량은 약 3.2MB다. 출처와 해시는 [fonts README](../assets/fonts/README.md) 참조.

굵기는 400/500/600/700. 세리프·모노스페이스·650/780 같은 임의 굵기와 제목의 음수 자간을 제거했다. 가격은 같은 Inter의 tabular-nums. 상품 모형에 인쇄된 작은 OSULLOC 글자는 UI 레이블이 아닌 그림의 일부다.

| 역할 | 크기 / 행간 / 굵기 |
|---|---|
| 페이지 제목 | 28 / 36 / 700 |
| 메인 비주얼 카피 | 28 / 36 / 600 |
| 구좌 제목 | 22 / 30 / 600 |
| 패널·캔버스 제목 | 16 / 24 / 600 |
| 본문·입력·설명 | 14 / 22 / 400 |
| 레이블·상품명 | 13 / 20 / 500 |
| 가격 | 14 / 20 / 600 |
| 보조 정보 | 12 / 18 / 400 |

기초 토큰의 `body` 15/24는 넓은 설명 문서용, `body-small` 14/22는 편집 앱용이다. 간격·타입 토큰을 px로 고정해 body의 14px 설정에 따라 기존 rem 값이 12.5% 작아지던 차이를 없앴다.

## 아이콘과 액션

`src/app.js`의 `ICON_PATHS` + `icon(name)`가 공통 SVG 컴포넌트다. 24px 그리드/1.75 stroke, 텍스트와 함께 16px, 단독 버튼 20px. undo/redo/추가/닫기/더 보기/목록/패널/교체/재제안/방향/주의를 같은 방식으로 표시한다. 드래그 핸들의 3px round 점은 선이 아닌 점의 광학 크기다. SVG는 aria-hidden, 단독 버튼은 이름을 제공한다. 버튼 문구와 기존 이벤트 계약은 유지한다.

주 행동은 Tea Green 채움, 보조 행동은 무채색 채움·얇은 테두리, 낮은 강조는 텍스트. 버튼 44px/compact 36px, 터치 환경 44px. 모두 pill 반경. 구좌 추가처럼 다른 작업 영역의 주 행동은 해당 영역 안에서만 강조한다.

## 구좌의 간격

- 좌우 24px, 상단 40px(구좌 번호 포함), 하단 32px.
- 제목→설명 8px, 설명→상품 24px, 카드 사이 16px(3열만 12px).
- 이미지→상품명 12px, 상품명→가격 4px. 상품명은 최소 두 줄 높이를 확보해 가격 정렬.
- 상품→CTA 24px. 정가는 판매가 아래 보조 정보로 분리.
- 선택/미적용 후보는 절대 위치 ring으로 표시해 내용 폭·높이가 달라지지 않음.
- 패널 padding 20px, 카드 24px, 폼 필드 사이 24px.

## 컬러와 참고 범위

사용자 제공 `DESIGN-mobbin.md`의 무채색 표면·자연스러운 자간·굵기 위계·8px 리듬·그림자 절제·pill 액션을 편집 앱에 맞춰 반영했다. 첨부 문서는 참고 자료이며 마케팅 페이지의 80px 제목/120px 구간 간격·상용 Saans·블루는 가져오지 않았다.

브랜드 `#397D49`, 선택 배경 `#F2F7EE` 유지. 중립색은 Ink `#141414`, soft canvas `#F3F3F3`, hairline `#DEDEDE`. 경고·오류·임시 후보는 기존 의미 색을 유지한다. 캠페인 목업의 이미지를 표현하는 색은 UI 액센트와 구분한다.

## 소스와 빌드

`src/fonts.css` → `design/tokens_v2.2.css` → `src/styles.css` → `src/theme.css`. 앱 로직은 `src/app.js`, 앱 템플릿은 `src/template.html`, 가이드 템플릿은 `design/guide.template.html`. `python3 scripts/build.py`가 앱과 가이드를 함께 생성하며 `--check`는 두 산출물의 최신 상태를 검사한다. 생성 HTML은 직접 편집하지 않는다. v0.2/v2.1 자료는 이력으로 보존한다.

데이터 구조·저장 키·가격 적용·레퍼런스 탐색의 확정 계약은 그대로다. 단, 필드 blur 때 상단 전체를 다시 만들던 처리 때문에 첫 Undo 클릭이 사라지는 현상은 같은 화면에서 버튼 노드를 유지하도록 수정했다. 변경은 기획 내용이나 가격 정책에 영향을 주지 않는다.

S07의 구좌/요청사항 병렬 대응과 A4 가로 인쇄 스타일을 보존했다. 실제 PDF 파일 저장/페이지 분할은 이번 검증에 포함하지 않았다.
