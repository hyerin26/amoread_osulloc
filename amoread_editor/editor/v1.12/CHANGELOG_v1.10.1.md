# v1.10.1 — 배치·이미지 속성 충돌 해결
- 상품 메이슨리의 이미지가 모두 동일 비율로 강제되던 문제 수정.
- 메이슨리에서는 상품별 기본 비율을 다르게 보여주고, 상품별 수동 설정/자동 복원 지원.
- 그리드·리스트·와이드·캐러셀은 기존 공통 이미지 비율을 유지. 메이슨리 설정은 다른 배치와 독립.
- 메이슨리 전환 시 적용되지 않는 공통 이미지 비율 컨트롤을 숨기고, 상품별 컨트롤로 교체.
- 모든 상품 비율 동일 또는 상품 1개인 경우 충돌 안내 제공.
- 기존 하드코딩된 메이슨리 nth-child 이미지 높이 CSS를 제거하고, 단일 렌더러의 상품별 비율을 사용.
- 구좌 유형 선택기와 중앙 프리뷰에 동일 해석 규칙 적용.
- 기존 구좌 종류/실제 가격 데이터/후기/CTA/토큰/기존 비율 데이터 삭제 없음.
- 상세 처리 원칙: `LAYOUT_CONFLICT_POLICY_v1.10.1.md`.
