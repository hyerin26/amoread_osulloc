Editor UI Kit · v1.12

기존 Green UI v2.5.1 토큰 위에서 조합하는 편집기용 컴포넌트. 상태·간격·위계 사용 기준. 중앙 고객용 상품 와이어프레임 디자인이 아닙니다.

← 통합 편집기 · 설계 명세

1. 버튼 위계

Primary는 현재 화면의 핵심 동작에 한 개만. Secondary와 Subtle은 보조 작업.

Hover · focus-visible · pressed · disabled

2. 상·하위 탐색

상위는 언더라인 탭, 하위는 보조 네비게이션. 하위 항목이 하나면 제목만.

문구 편집

실제 편집기에서는 그룹에 하위 항목이 2개 이상일 때만 보조 탭 표시.

3. 텍스트 필드

레이블 ↔ 입력: 4px, 필드 ↔ 다음 필드: 12px. 도움말과 오류는 필드 바로 아래.

4. 입력 상태

올바른 URL을 입력하세요.

5. Switch / Checkbox

즉시 변경은 스위치, 다중 선택은 체크박스.

6. 선택 옵션 / 필터

상품 리스트에서는 열 수 옵션을 숨기고, 캐러셀에서는 ‘노출 카드 수’라고 표시.

7. 아코디언

고급 표시 옵션 펼치기

상품별 카드 요소, 간격 예외 등을 입력합니다. 필수 설정은 접힌 안에 숨기지 않습니다.

8. 스켈레톤 / 빈 상태

연결된 상품 없음자료에서 상품을 선택하세요.

로딩이 아닐 때 스켈레톤을 보여주지 않아요.

9. 아이콘

SVG Sprite · 스트로크 1.8px · 16/20px. 아이콘 버튼에는 aria-label 필수.

10. 반복 항목

항목 안은 12px, 항목 간 8px, 그룹 간 24px.

11. 다이얼로그 / 토스트

Dialog는 중요한 선택·확인, Toast는 짧은 비차단 피드백.

12. 간격 표준

Green UI의 기존 s1~s6만 별칭으로 사용. 새 전역 컬러/폰트 토큰 추가 금지.

구좌 유형 선택

현재 페이지에 추가할 레이아웃을 선택합니다.
