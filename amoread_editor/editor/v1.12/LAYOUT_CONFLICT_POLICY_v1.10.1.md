# AMOREAD 구성·속성 충돌 처리 원칙 — v1.10.1

## 문제와 목표
기존 v1.10에서는 `imageRatio=1:1` 같은 **구좌 공통 속성**을 '메이슨리' 상품 배치에도 똑같이 적용해 서로 다른 이미지 높이라는 레이아웃의 본질을 무너뜨렸다. 단순한 CSS 보정이 아니라, **각 편집 옵션의 적용 범위와 우선순위를 명시**한다. 기존 데이터를 임의 삭제하거나 다른 기능을 조용히 비활성화하지 않는다.

## 1. 의미적 우선순위 (높은 순)
1. **구조적 제약/사용자 안전** — 레이아웃이 성립하기 위한 조건, 읽을 수 있는 최소 크기, 이미지/문구의 겹침 방지. 내용이 잘리는 레이아웃은 허용하지 않는다.
2. **배치 방식(Layout recipe)** — 그리드는 일정한 열, 메이슨리는 서로 다른 세로 길이, 리스트는 정보가 옆에 붙는 한 열, 캐러셀은 한 화면 노출 장수라는 구조적 의미를 지닌다.
3. **해당 객체의 명시적 사용자 설정(Instance override)** — 개별 상품 카드가 지정한 이미지 비율·표시 요소·문구는 해당 카드에만 적용한다. 단, 1·2를 깨는 상황에서는 충돌 안내를 제공한다.
4. **구좌 공통값(Section default)** — 위 조건에 적용되지 않을 때만 사용한다. 그리드/리스트/와이드 카드/캐러셀에는 `imageRatio`; 메이슨리에는 별도 `productImageRatios[상품 ID]`를 사용한다.
5. **안전한 기본값(Fallback)** — 상품 구좌 1:1, 기타 이미지 구좌 4:3. 메이슨리 이미지에는 카드 순서별 3:4 → 1:1 → 4:3 → 9:16 → 16:9 패턴.

**중요:** 우선순위는 하위 데이터를 덮어써 삭제한다는 뜻이 아니다. '현재 레이아웃에서 무엇이 실제 출력되는가'를 결정하는 **해석 순서**다.

## 2. 배치와 편집 필드의 호환성 매트릭스

| 배치/구성 | 열/노출 수 | 이미지 비율 | 상충 시 UI 동작 |
| --- | --- | --- | --- |
| 상품 그리드 | 1–4열 | 구좌 공통 비율(기본 1:1) | 명시한 공통 비율을 모든 카드에 적용 |
| 상품 리스트 | 구조상 1열 고정 | 구좌 공통 비율 | 무의미한 열 수 컨트롤을 숨김·저장값 보존 |
| 와이드 카드 | 구조상 1열 고정 | 구좌 공통 비율 | 무의미한 열 수 컨트롤을 숨김·저장값 보존 |
| 상품 캐러셀 | 1–4장/뷰 | 구좌 공통 비율 | 이름을 '한 화면에 보이는 카드 수'로 변경 |
| **상품 메이슨리** | 1–4열 | **상품별 비율(자동 또는 개별)** | **구좌 공통 비율 컨트롤 대신 상품별 이미지 비율 컨트롤 표시**. 기존 공통값 유지 |
| 재사용 상품 카드 블록 | 주변 구좌와 독립 | 해당 블록 비율 | 블록 자체의 비율이 주변 구좌의 비율을 우선 |
| 일반 안내·스토리·레퍼런스 | 콘텐츠 구조에 따라 1–3열 | 구좌 공통 비율 | 자유 기획의 프레임 최소 높이는 실제 콘텐츠 높이보다 낮아질 수 없음 |

## 3. 메이슨리 충돌 해결의 실제 동작
- 기존 전역 이미지 비율 16:9에서 '메이슨리'로 바꾸면 **16:9 값은 저장한 채** 화면에서 사용하지 않는다. 선택기에는 16:9가 그대로 적용되는 것처럼 표시하지 않는다.
- 메이슨리에서는 각 상품의 **자동 조합**이 기본이다. 서로 다른 높이의 이미지가 즉시 보이게 한다.
- 상품별 `자동 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16` 중 선택할 수 있다. 설정은 상품 ID로 연결되어 순서를 바꿔도 해당 상품에 붙는다.
- **모든 상품을 같은 비율로 수동 설정했을 때:** UI에 '메이슨리 높낮이 차이가 사라진다'는 경고를 노출하고 '모든 이미지 높이 자동 조합으로 복원'을 제공한다. 사용자가 의도적으로 같은 비율을 선택할 자유는 보존하되, 무의식적 충돌은 명확히 알린다.
- 상품이 한 개라면 메이슨리의 차이가 드러나지 않는다고 안내한다.
- 그리드 등으로 되돌리면 기존 전역 비율을 다시 사용한다. 메이슨리의 상품별 선택도 다음 메이슨리 전환을 위해 유지한다.

## 4. 모든 기능에 적용하는 충돌 처리 체크리스트
- **적용 범위(scope) 확정:** 페이지/구좌/블록/카드/하위 요소 중 어느 단위인지 먼저 정의한다.
- **호환성 확정:** 선택 가능한 조합 / 의미가 없는 조합 / 제한된 조합을 구분한다.
- **무의미한 옵션 숨김:** 단순히 선택할 수 있지만 작동하지 않는 입력은 제공하지 않는다. 이전 값은 숨김 상태로 보존한다.
- **변화 이유 안내:** 레이아웃 변경 시 기존 값이 적용되지 않는 이유와 돌아갈 방법을 즉시 설명한다.
- **예외값의 범위 격리:** 구좌 기본값을 편집해도 별도 블록의 명시적 설정을 덮지 않는다.
- **미리보기·저장·내보내기 일치:** 중앙 전체 페이지, 유형 라이브러리, 저장 재로딩, 디자이너 HTML 모두 동일한 해석 함수에 의존해야 한다.
- **회귀/조합 테스트:** 뷰 전환, 개별 속성 변경, 다시 전환, Undo/Redo, 저장·복원, 노출 개수 1~4, 좁은 모바일 폭을 자동 검증한다.
- **데이터 마이그레이션:** 기존 `imageRatio`, `layoutColumns`, 카드 토글/가격/CTA/후기 데이터는 삭제·치환하지 않고 별도 확장 필드로 보완한다.

## 5. 데이터 계약
- `section.imageRatio`: **메이슨리 이외** 배치에서 사용하는 공통값. 기존대로 유지.
- `section.productImageRatios`: 선택적 `상품 ID → 비율` 맵. **메이슨리**에서만 렌더링에 사용. 키가 없는 상품은 자동 조합. 사용자가 '자동'으로 되돌리면 해당 키를 제거.
- 다른 구좌에 넣는 독립 `productCard` 블록은 기존 `block.props.imageRatio`를 사용. 상위 구좌의 메이슨리 여부가 블록의 비율을 바꾸지 않는다.
- 현재는 상품 원본 이미지 메타데이터 미연동이므로 이미지 비율은 **기획용 placeholder 비율**이다. 실제 이미지 연결 시에는 자연 비율/크롭/포커스 정책을 별도로 검수해야 한다.

## 미완료/외부 연동
실제 오설록 상품 이미지의 자연 비율 자동 추출, 품질 좋은 크롭 기준점, 실제 쇼핑몰 모바일 breakpoints, 운영 캐러셀 터치·무한 루프, 사내 SKU 저장 스키마 등은 아직 연결하지 않았다. 위 정책은 현재 **기획용 와이어프레임**에서 검증하는 계약이다.
