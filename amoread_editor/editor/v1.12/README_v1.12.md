`http://localhost:8000/integrated/v1.12/` 접속.

## 구성 구조 · 구성 블록 · 상세 속성 품질 보강 (2026-11-14)

v1.12 편집기 `block-quality.css`는 **고객 노출 구좌의 기획 와이어프레임 전용 스타일**입니다. 기존 Green UI v2.5.1 토큰/편집기 chrome을 변경하지 않고, 원래 구좌와 추가 가능한 블록을 동일한 간격 원칙으로 배치합니다.

- **상세 속성:** 상품 카드 안의 이미지 → 상품명 → 가격·할인 → 후기·설명 → CTA 간 간격을 역할별로 구분. 혜택의 비어 있는 조건을 빈 문단으로 그리지 않고, 유의사항·후기·혜택을 각각 읽을 수 있는 카드로 표현.
- **구성 블록:** 그룹의 간격(8/12/20px), 내부 여백(8/12/20px), 정렬(상단/중앙/채움)을 별도로 설정. 기본형·그리드형·가로형 간 전환 시 항목 데이터는 그대로 유지.
- **구성 구조:** `split`의 이미지/텍스트 1:1·2:1·1:2 비율과 이미지 좌/우/상단 배치를 화면에 반영. 혜택·서비스·스토리·일정·유의사항 및 상품 컬렉션은 340px 미리보기 **프레임 폭 기준**으로 열 수를 자동 조정. 표준 340px 편집 프레임에서는 사용자가 선택한 3/4열을 그대로 표시하고, 260px 미만의 극소형 영역에서만 1열로 접음.
- **인계 주의:** 열 자동 접힘은 CSS 표현에만 적용되며 저장된 `columns`, 문구, 상품 ID와 기존 블록 순서는 변경하지 않음. Green UI는 편집기 조작용, 오설록 미리보기는 기획 구성용으로 분리함.

검증: `python test_block_quality_v112.py`는 340px/230px 프레임과 그룹 변경, 실제 CSS gap/padding, 설정된 4열 표시 및 극소형 1열 전환, `split`의 비율, 편집값 보존을 검사합니다. `run_regression_v112.py`에 포함되어 있습니다.

**남은 검증:** 실제 브랜드별 프로모션 원본과 대조한 시각 QA, 사내 토큰/CSP, 자동 생성 인계 HTML에서의 스타일 동등성 및 접근성 테스트는 별도 확인이 필요합니다.

## 설정 반영·캔버스 삭제 개선 (2026-11-14)

- 가운데 요소를 선택하면 컨텍스트 툴바에서 **설정·복제(지원되는 요소)·삭제**를 사용할 수 있습니다. Delete/Backspace로 삭제하고 상단 **실행 취소**로 복원할 수 있습니다. 기존 우측 인스펙터 삭제 기능도 유지합니다.
- 상품 카드 내 개별 속성을 삭제하면 해당 상품 카드에서만 숨깁니다. 해당 카드를 선택해 우측 ‘카드 속성’에서 다시 표시할 수 있습니다. 전체 구좌의 16개 카드 요소 설정과 별도로 동작합니다.
- **혜택 총정리 3열**, 상품 4열, 정보 구좌 항목 간격, 혜택 유형, 메인 비주얼 위치·여백, 분할 비율·교차 이미지, 아코디언 밀도, 특가 상품 노출, 종료 후 CTA, 작은 상품 카드 밀도 등의 설정과 중앙 미리보기 연결을 수정했습니다.
- 비주얼 배치는 ‘배치·표시’, 특가/카운트다운 종료 상태는 ‘동작·조건’에서 편집합니다. 적용 불가 옵션은 숨기거나 이유를 안내하며 기존 설정값은 보존합니다.
- 상세 목록 및 제한: [SETTING_REFLECTION_AUDIT_v112.md](SETTINGS_REFLECTION_AUDIT_v112.md).

회귀 테스트: `python run_regression_v112.py`에 추가한 `test_settings_audit_v112.py` 및 `test_settings_matrix_v112.py` 포함. CI/실브라우저 확인 결과가 나오기 전에는 자동 테스트 통과로 표기하지 않습니다.

## 2026-11-14 작업 재개: 세부 요소 선택·드래그·미리보기 문구 정리

- **중앙 ↔ 우측 패널 연결:** 혜택 2번, 상품 카드의 특정 속성, 후기·중첩 블록을 누르면 우측에서 대응하는 반복 카드/필드가 강조되고 해당 독립 스크롤 영역이 이동합니다.
- **혜택 아코디언 이미지:** 서비스 구좌의 이미지 없음/상단/좌측/우측/교차 옵션이 펼친 내용에 적용됩니다. 아코디언이 사용하는 1열과 일반형의 3열 값은 구분하며, 전환 시 저장한 열 수를 보존합니다.
- **상품 카드 16개 요소:** 요소별 체크박스, 필요한 경우에만 열리는 한 항목의 내부 설정, 독립 스크롤 가능한 요소 목록, 드래그 정렬 및 ↑↓ 버튼으로 편집합니다. 미선택 요소의 문구 입력 필드는 DOM에 생성하지 않습니다. 운영 API가 연결되지 않은 AI 요약은 비활성화합니다.
- **조건부 정렬:** 이미지 위 모서리 라벨은 이미지 내부 오버레이이므로 이미지 사용 중에는 순서 이동을 막고, 이미지가 꺼져 카드 본문에 표시될 때만 이동할 수 있습니다. 설정값을 바꿔도 기존 작성 문구는 보존됩니다.
- **좌측 구성 트리:** 같은 부모/구좌 내부의 혜택·상품·후기·퀴즈·중첩 블록을 드래그하여 재정렬합니다. 다른 구좌/그룹으로 이동하는 드롭은 거부하며, Alt+↑/↓와 실행 취소도 지원합니다.
- **고정 문구 정리:** 편집 필드에 없는 장식적인 `BENEFIT`, `RESULT BENEFIT`, `QUESTION FLOW` 등의 고객 미리보기 문구를 제거하고 분할/텍스트 CTA에 기존 작성 데이터를 사용합니다. 이미지 자리·상품 원본 데이터·상태 표시는 구조적 표시로 구분합니다.

신규 브라우저 검증: `test_inspector_navigation_v112.py`, `test_linked_controls_v112.py`, `test_composition_interactions_v112.py` (전체 19개 항목에 포함).

**검증 상태:** GitHub Actions의 2026-11-13 20:23 UTC 실행은 모든 작업이 약 2~3초 만에 실패하고 작업 로그 다운로드도 오류를 반환하였습니다. 실제 Chromium 회귀 테스트 통과 여부는 **확인되지 않았습니다**. 별도 JS 실행으로 구성 블록·드래그 재정렬·조건부 속성 렌더링·하드코딩 문구 삭제 등 순수 로직은 점검하였으나, 브라우저 상호작용 검증을 대체하지 않습니다.

## 제한 / 사내 GitLab 이식
- 실상품·후기·쿠폰·사내 시스템 API는 미연동. 현재 가상 데이터 기반 기능 프로토타입.
- 실사 고객 노출 UI가 아니라 내부 편집기 컴포넌트 규칙이다.
- `tokens.demo.css`는 사내 반입 시 정식 Green UI로 교체하고, CSP에서 inline SVG `<use>` 가능 여부를 확인한다.
- Skeleton/오류/네트워크 로딩 상태 중 일부는 **디자인 규격·갤러리**이고, 운영 API 연결은 미완료.
- 저장 모델을 변경하지 않는다. 기존 구좌/카드/문구/후기/이벤트/검수 기능은 회귀 테스트 대상이다.
