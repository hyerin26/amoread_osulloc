# AMOREAD v1.8 — 구좌 UI 정합성 + 자유 기획/레퍼런스 구좌

## 변경 원칙
- 이전 v1.2~v1.7의 기능(21종 구좌, 상세 편집 탭, 퀴즈 다중 문항/결과, 이벤트 6종, 후기 4종, 상품 16개 구성 요소, CTA, 블록 선택/삽입, Undo/Redo, 저장, HTML 인계)을 **삭제하지 않았음**.
- 기존 Green UI v2.5.1 토큰은 변경하지 않고 편집기 전용 CSS 레이어에 규칙 추가.
- 구좌 선택기에서는 **기존 21종 + 새 자유 기획 1종**, 상품/후기/아코디언 구조별 시각적 변형을 계속 볼 수 있음.

## 구좌 선택기·레이아웃 겹침 해결
- `layout-integrity.css`: 썸네일 카드의 `grid-auto-rows: max-content`, 제목·설명용 별도 행, 가로·세로 비율 유지, 줄바꿈과 자동 크기 계산.
- 제목·설명·가격·카드 내용이 길어도 다음 행이나 다른 구좌에 겹쳐 보이지 않도록 카드/미리보기 그리드 크기 제한 수정.
- 선택기 썸네일의 실제 원본 폭 340px 보존, 긴 부분만 안전하게 잘라 표시하고 전체 보기 기능 유지.

## 상품 카드 모서리 라벨
- 기존 요소 `label`은 이미지에 닻을 내린 **모서리 라벨**로 렌더링, `pill`은 본문 흐름에 표시되는 독립 알약형 요소로 구분.
- 모서리 라벨 기본 위치는 좌상단. `top-left`, `top-right`, `bottom-left`, `bottom-right` 선택 가능.
- 상품 그리드, 리스트, 와이드, 캐러셀, 메이슨리와 `productCard`/`productGrid` 블록에 동일한 렌더 함수 사용.
- 이미지 요소를 숨겼으나 라벨은 켠 경우에는 사용자에게 사진이 없어 모서리에 붙일 수 없음을 알리는 대체 표현 사용.
- 이미지/상품명 등의 재정렬은 기존 `card.order`에 따름. 라벨 자체는 이미지에 고정되어 순서를 바꿔도 위치가 변하지 않도록 제어.

## 신규 `custom`: 자유 기획 · 레퍼런스 구좌
- **22번째 기본 구좌**로 추가. 이전 구좌 유형 ID를 삭제·변경하지 않음.
- 위치·높이·화면에서의 상태(아이디어/검토 필요/인계 준비) 설정.
- 표현 방식: 빈 구조(위치 먼저 확보), 참고 이미지, 추가 블록 직접 구성.
- 기획 의도, 참조 원본 URL, 참고할 배치·카피·분위기, 인터랙션·상태 메모 입력.
- PNG/JPEG/WebP 이미지를 브라우저에서 WebP로 축소 후 가상 기획안 LocalStorage에 저장(최대 약 800KB data URL). 용량 초과 시 기존 이미지를 보존하며 오류 안내.
- 고객 노출 이미지가 아님을 시안·인계에 명시. URL은 http(s)만 허용.
- 기존 요소 라이브러리를 통해 상품 카드/CTA/텍스트 등 재사용 블록 추가 가능.
- 유형 변경시 이전 유형별 데이터는 `variants`에 보존하고 Undo/Redo 지원. 원본 구좌 제목/설명/CTA/참고 사항 유지.
- 검수 탭: 목적 누락, 레퍼런스/블록 누락, URL 형식, 인계용 인터랙션/디자인 요청 확인.

## 구현/운영 구분
- **본 패키지는 로컬 브라우저 UX 프로토타입**. 사내 GitLab API/상품 실데이터/후기 Excel/운영 정책/미리캔버스 같은 완전 자유형 좌표 배치는 미연동.
- 인계 HTML은 시각·구조 전달용 시안이며, 이미지/위치/메모/CTA 정보를 포함하지만 실제 운영 프론트엔드가 아님.
- 상품 카드의 AI 후기 요약은 외부 서비스 미연동으로 비활성 유지.
