# AMOREAD v1.8 통합 편집기

기존 v1.2~v1.7 UX와 Green UI 기반을 보존한 작업용 프로토타입. 신규 자유 기획 구좌와 모서리 라벨/선택기 겹침 보완을 포함합니다.

## 로컬에서 실행

ZIP 압축을 해제하고 `index.html`을 Chrome/Edge에서 열거나 아래 명령으로 실행합니다.

```bash
python -m http.server 8000
```

브라우저 `http://localhost:8000/` 접속. GitHub 저장소에서 실행 시 `http://localhost:8000/integrated/v1.8/`.

## 새 구좌 활용 예시

1. 좌측 구좌 목록에서 `+ 구좌 추가`를 눌러 `자유 기획 · 레퍼런스 구좌`를 선택.
2. 위/아래 이동으로 전체 프로모션의 어느 위치에 배치할지 결정.
3. 우측 `자유 구성 · 레퍼런스` 탭에서 아이디어 상태, 높이와 참고 URL/이미지 첨부.
4. 좌측 `요소`에서 상품 카드/텍스트/이미지/CTA 등을 넣어 개략 구조 구성.
5. 이미지가 참고 자료임을 확인하고, 디자인 요청 및 인터랙션·조건을 입력.
6. `검수` 탭에서 기획 의도/참고 자료/연결 누락을 확인하고 인계 HTML을 출력.

## 모서리 라벨

상품 구좌의 `카드 모양` 탭 또는 삽입된 상품 카드 속성에서 **모서리 라벨**을 켜고 위치를 설정. 이미지 자리 위에 겹쳐 표시됩니다. **알약**은 별도 일반 텍스트 요소입니다.

## 실행 및 QA

```bash
python test_v18.py

```

기존 v1.2~v1.7 테스트 스크립트도 포함합니다. Python Playwright와 Chromium 필요. 실제 사내 GitLab, 상품/후기 API, 자동 AI 후기 요약, 운영 이벤트 실행, PDF 출력은 미연동입니다.

## 저장/보안

LocalStorage에 가상 기획안을 저장합니다. 참고 이미지 첨부는 해당 브라우저 로컬 공간에 보관되며, 첨부 후 용량 오류가 나면 기존 상태를 되돌립니다. 외부 URL을 서버에서 자동 크롤링하지 않습니다. 내부 데이터·고객 정보는 이 GitHub 실험용 저장소에 커밋하지 마세요.
