# AMOREAD Integrated v1.11 — 정보구조 개편

## 기준 / 범위

- v1.10.1 소스 전체 복사 후 **탐색·선택·패널 UI 중심으로 점진적 변경**
- 기존 22개 구좌, 9개 블록, 퀴즈·이벤트, 후기, CTA, 상품 카드 16개 요소, 프레임 높이, 이미지 비율·메이슨리 충돌 처리와 구좌 선택기 유지
- 사내 Green UI 토큰 `tokens.demo.css` 등 기존 CSS 수정 없음. 신규 `ia-v111.css`에서 편집기 정보구조에 필요한 UI만 추가

## 1. 좌측 `구성 / 추가 / 자료`

- **구성:** 계층 트리(구좌 → 구좌에 포함된 상품/반복 항목/후기/퀴즈 화면/삽입 블록/그룹). 구좌 접기·펼치기, 기존 순서 변경·복제·삭제 유지. 그룹 아래 블록까지 보이도록 표시.
- **추가:** `구좌 추가`와 `요소 추가`를 하나의 좌측 패널에서 전환. 구좌는 기존 전체 비율 미리보기 선택기 재활용. 요소는 기존 카탈로그·드래그 삽입 재활용.
- **자료:** 가상 상품·후기·레퍼런스 리스트와 연결 동작. 현재 선택한 개별 상품 카드나 후기 블록에 링크하거나, 구좌의 상품/후기 목록에 추가. 원본 데이터와 UI 블록의 차이를 안내.

## 2. 우측 선택 대상 / 속성 그룹

- `페이지 > 구좌 > 요소` 선택 경로, 구좌 전체 또는 개별 요소 적용 범위 안내, 경로를 통한 부모 복귀
- 기존 탭/기능 렌더러 삭제 없이 `내용 / 배치·표시 / 동작·조건 / 참고·인계 / 검수` 목적별 그룹화
- 같은 그룹 안에서 기존 세부 항목을 전환하므로 기존 필드 저장 스키마·이벤트 핸들러 그대로 사용
- 상품 카드 16개 요소는 하위 `상세 설정` 펼침 영역으로 관리. AI 후기 요약은 기존과 같이 사내 연동 전 비활성
- 히어로처럼 기존 우측 `카드 모양` 탭이 없던 이미지형 구좌에도 `배치·표시 > 이미지 비율` 접근 가능하도록 별도 진입점 보장

## 3. 전체 검수

- 헤더 `전체 검수` 버튼에서 구좌별 정적 오류·경고를 모아 확인
- 항목 선택 시 해당 구좌의 검수 편집 영역으로 이동
- 사내 법무·운영 정책 승인이나 실제 구매 데이터 검증이 아님

## 검증

- `python test_ia_v111.py`: 3개 좌측 모드, 구성 트리, 구좌/블록 컨텍스트, 자료 연결, 퀴즈 결과 선택, 검수 동선 테스트
- `python run_legacy_compat_v111.py`: 기존 v1.2~v1.10.1 테스트에서 **구 화면 위치를 찾는 명령만** 변경된 탐색 동선에 연결해 실제 기능 회귀를 검사. 원본 테스트 소스는 그대로 남겨둠.
- `python capture_ia_v111.py`: 3가지 좌측 모드 스크린샷 생성
