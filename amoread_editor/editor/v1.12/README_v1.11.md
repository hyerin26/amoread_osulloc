# AMOREAD Integrated v1.11 · IA 개선판

**이 버전의 기준은 v1.10.1 전체 소스**이며, 기존 기능과 테스트를 보존하는 방식으로 정보구조를 개선했습니다.

## 실행

프로젝트 루트에서:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/AMOREAD_Integrated_Composable_v1.11/` 또는 GitHub 폴더 기준 `http://localhost:8000/integrated/v1.11/`을 엽니다.

## 3단계 편집 흐름

1. **구성**: 페이지 안의 구좌와 자식 요소를 찾거나 구좌 순서를 바꿉니다.
2. **추가**: 구좌·요소 라이브러리에서 새로운 구성을 삽입합니다.
3. **자료**: 가상 상품·후기·레퍼런스에서 원본 콘텐츠를 선택한 대상에 연결합니다.
4. **오른쪽**: 현재 선택한 구좌나 요소의 `내용/배치·표시/동작·조건/참고·인계/검수` 설정을 편집합니다.

왼쪽 구좌·요소와 중앙 미리보기는 같은 편집 대상으로 연결됩니다. 오른쪽 헤더의 경로를 누르면 상위 구좌로 돌아갑니다. 각 설정은 이전 v1.10.1의 필드명과 저장 모델을 그대로 사용합니다.

## 주요 검증

```bash
python integrated/v1.11/test_ia_v111.py
python integrated/v1.11/run_legacy_compat_v111.py
```

기존 테스트는 과거 화면 구조를 전제로 하기 때문에 `run_legacy_compat_v111.py`가 **테스트 세션에서만** 옛 탭을 펼치고 추가 라이브러리 하위 모드로 이동시킵니다. 실제 편집기 화면에는 적용되지 않습니다.

## 사내 이식 시 주의

이 프로토타입은 가상 데이터를 사용합니다. 실제 운영용 상품·할인·후기/이벤트 API, 사내 Green UI CSS, Pydantic 저장 필드, CSP, 디자이너 HTML/PDF 인계는 최신 사내 GitLab 코드와 별도로 검증해야 합니다. 기존 GitLab 원본을 삭제하거나 덮어쓰지 마세요.
