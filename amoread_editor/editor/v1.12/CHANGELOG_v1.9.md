# AMOREAD v1.9 — 자유 기획 프레임 높이 조절

## 주요 변경

- 기존 22종 구좌와 Green UI, 구좌/요소 전환 레일, 퀴즈·후기·CTA·상품 카드 상세 편집을 유지하고 **자유 기획 구좌만 확장**.
- 자유 기획 프레임 아래쪽에 **세로 크기 조절 손잡이** 추가. 가운데 모바일 와이어프레임에서 드래그해 최소 높이를 20px 단위로 조정(160~1600px).
- 손잡이는 키보드 위/아래(20px), Shift+위/아래(100px), Home/End 지원. 단순 클릭에는 편집 이력 남기지 않음.
- 우측 자유 구성·레퍼런스 탭에서 높이 프리셋(콘텐츠 맞춤, 짧게, 기본, 길게)과 px 직접 입력, 자동 맞춤 지원. 프리셋 선택 시 수동 높이 해제.
- `custom.height` 기존 필드를 유지한 채 `custom.heightPx` 선택적 필드 추가. 구버전 LocalStorage 기획안 자동 호환.
- 기존에는 구좌 바깥에 위치하던 추가 블록을 **자유 기획 프레임 안으로 이동**. `section:after` 원래 Slot 키는 보존하고 중복 렌더링 금지.
- 높이는 `min-height`로 적용하여 참고 이미지·텍스트·상품 카드가 설정값보다 길어지면 **자동 확장**, 내용이 잘리지 않도록 처리.
- 디자이너 인계 HTML에 프레임 높이 스타일과 내부 블록 구성 반영. 편집 손잡이는 인계 화면에서 제외.
- 짧게 프리셋에서 기획/인터랙션 메모가 숨겨지던 기존 규칙 해제.
