# 카드 요소 16개 기능·시각 의미 QA

| ID | 의미 | 데이터 출처 | 미리보기 적용 | 유의사항 |
|---|---|---|---|---|
| `img` | 상품 사진 | 상품 | 표시·숨김, 순서 | 실제 상품 이미지 대신 자리 표시 |
| `label` | **사진 모서리 배지** | 직접 입력 | 표시·숨김, 모서리 위치 4종 | 이미지 숨김 시 별도 경고 표현; 사진과 함께 이동 |
| `pill` | 알약형 짧은 정보 | 직접/운영 조건 | 표시·숨김, 본문 흐름 | 모서리 배지와 다르게 이미지 위에 붙지 않음 |
| `appeal` | 상품별 소구문구 | 상품별 직접 입력 | 표시·숨김, 내용 반영 | 상품 개별값 유지 |
| `tag` | 상품명 앞 태그 | 직접 입력 | 표시·숨김 | 별도 inline 태그 |
| `name` | 상품명 | 상품 | 표시·숨김 | 줄바꿈 가능 |
| `list` | 정가 | 상품 | 표시·숨김 | 가상 값 |
| `first` | 1단 할인 가격 | 상품 | 표시·숨김 | 2단 할인 미적용이면 안내 표현 |
| `pct` | 할인율 | 상품 가격 계산 | 표시·숨김 | 가상 할인 계산 |
| `pname` | 가격 종류명 | 상품 정책 | 표시·숨김 | 할인/추가 혜택가 명칭 |
| `sale` | 최종 판매가 | 상품 | 표시·숨김 | 가상 값 |
| `rating` | 별점·리뷰 수 | 상품 | 표시·숨김 | 실 후기 API 미연동 |
| `review` | 후기 한 줄 | 상품 | 표시·숨김 | 가상 인용문 |
| `ai` | AI 후기 요약 | 사내 AI 예정 | 비활성 | 연결 전 허구의 AI 결과 표시 금지 |
| `copy` | 카드 추가 문구 | 직접 입력 | 표시·숨김, 줄바꿈 | 구좌 기본값/개별 블록 값을 구분 |
| `btn` | 카드 내부 버튼 | 직접 입력 | 표시·숨김 | 실제 클릭·이동은 기획용 시안 |

**구조 검수:** 상품 구좌와 `productCard` 블록 모두 `renderProductCardElements()`를 공유. `img` 위치는 기존 순서값에 따르되 `label`은 사진 모서리 배지로 고정. 기존 클래스 `.mock-el--label`을 보존해 과거 회귀 테스트와 식별을 유지.

**추가 후속 개발:** 실 상품 이미지/가격·후기 데이터 연결, SKU 단위 개별 텍스트 예외, 온라인 운영 가격 최종 적용, 실제 CTA 이동 및 AI 요약 생성은 사내 GitLab·API 통합 후 구현·검수해야 함.
