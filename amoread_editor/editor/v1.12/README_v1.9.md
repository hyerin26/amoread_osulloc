# AMOREAD v1.9 — Resizable Custom Section

v1.8의 모든 기능을 보존한 새 버전입니다. ZIP 압축 해제 후 `index.html`을 브라우저에서 열거나 `python -m http.server 8000` 실행 후 프로젝트 폴더에 접속하면 됩니다.

## 사용법

1. 구좌 유형에서 **자유 기획 · 레퍼런스 구좌**를 추가합니다.
2. 중앙 모바일 와이어프레임에서 해당 구좌를 선택한 뒤, 프레임 **아래쪽 초록색 손잡이**를 세로로 드래그합니다. 다른 구좌로 순서가 바뀌지 않습니다.
3. 정확한 크기가 필요하면 우측 **자유 구성 · 레퍼런스 → 프레임 최소 높이(px)** 에 입력합니다.
4. 텍스트·상품 카드 등은 좌측 **요소** 목록에서 추가합니다. 모두 자유 기획 프레임 **내부**에 들어갑니다.
5. 높이 프리셋으로 돌아가거나 **자동 맞춤**을 선택할 수 있습니다.
6. Ctrl+Z / Ctrl+Y, 예시 JSON, 디자이너 인계 HTML에서 크기 및 내용 보존을 확인할 수 있습니다.

## 규칙

- 드래그와 키보드는 20px 스텝. 손잡이에서 ↑/↓는 20px, Shift+↑/↓는 100px, Home/End는 최소/최대입니다.
- 수동 높이는 160~1600px 범위이고, **최소 높이**로 동작합니다. 들어간 콘텐츠가 더 길면 자연스럽게 커집니다.
- 기존 `custom.height` 프리셋 데이터는 삭제하지 않습니다. 기존 구좌/후기/상품/퀴즈/이벤트 기능 변경 없음.
- 편집 손잡이와 상태 UI는 고객에게 보여줄 확정 디자인이 아니므로 인계 HTML에 제외됩니다.
