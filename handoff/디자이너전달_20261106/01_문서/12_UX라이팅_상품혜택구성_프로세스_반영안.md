## 0. 디자이너 UX 라이팅 원칙 (요약)
1. 안내·오류·완료 문장은 해요체. 짧고 친근하되 정확하게
2. 누가 무엇을 하는지 드러나는 능동형. 결과·안심이 중요하면 '실제 판매 가격은 바뀌지 않아요'처럼 씀
3. 막혔다고만 하지 않고 다음에 할 일을 알려 줌. 안 되는 일(AI, 실데이터 연동)을 되는 것처럼 쓰지 않음
4. '하시겠어요', '확인 바랍니다', '처리 완료' 대신 자연스러운 문장
5. 명사 나열보다 동사로. 꼭 필요한 실무 용어('구좌', '레퍼런스')만 남김
6. 버튼·필드·탭·상태는 짧게('닫기', '가격 적용하기'). 모든 레이블을 문장으로 늘리지 않음
7. 오류는 잘못된 곳 가까이에서 이유와 해결 방법을 함께
8. 확인창 왼쪽 버튼은 '닫기'. 닫기·되돌리기·버리기를 '취소' 하나로 뭉뚱그리지 않음. 삭제·버리기의 결과를 분명히
- 다운로드는 '시작했어요'까지만 말함. 사용자가 쓴 카피·상품명·메모는 자동으로 고치지 않음

**주의 (바꾸면 안 되는 연결):** `engine.py`의 판정 문구 '할인율 없음'은 `amoread/checks.py`가 이 글자로 찾아 걸러요(107행). 바꾸려면 두 파일을 함께 고쳐야 해요. PROMO_WORK 엑셀 '검증' 시트에 들어가는 문구도 형식이 바뀌니 멘토님 확인 후에 바꿔요.

## 4. 디자이너 '상품·혜택' 화면 구성을 ② 상품·할인에 반영함
멘토님 툴 구성을 보기 전에 만든 화면이라 내용과 데이터 항목은 달라요. **배치와 위계만** 따랐어요.

| 디자이너 S05 | 우리 ② (반영함) |
|---|---|
| 작은 머리글 '03 · 상품·혜택' + 제목 '상품·혜택 검토' + 설명 + 오른쪽 주 버튼 | '② 상품·할인' + '상품·할인 검토' + 설명 + 오른쪽 저장 버튼(주 버튼). 다음 단계 버튼은 상단 단계 막대 |
| 안내 띠: '상품과 가격은 모두 예시예요. 기획안에서 가격을 바꿔도 실제 판매 가격은 바뀌지 않아요' | 안내 띠: '기획안의 할인만 바꿔요. 실제 판매 가격과 PROMO_WORK는 바뀌지 않아요. ⑤에서 내보낸 엑셀을 붙여 넣어야 반영돼요' |
| 카드 + 표(상품, 상품 코드, 정가, 내부 원가, 행사 판매가, 상태) | 묶음 탭(구좌 상품 · 하루특가 편성 · 후보 상품) + 작업대 표(열 구성은 그대로) |
| 행사 판매가 빨강, 숫자 열 오른쪽 정렬·같은 폭 숫자 | 작업대 표 할인가 열 빨강(`--price`), 숫자 열 같은 폭 숫자 |
| 표 아래: '내부 원가는 공유 문서에 표시하지 않아요' | 표 아래: '원가와 원가율은 이 화면에서만 보여요. 디자이너 기획안과 팀 공유 요약에는 넣지 않아요' |
| '수정됨' 배지 (처음 가격과 다름) | 아직 없음. 확정 뒤 바뀐 행 표시는 ⑤에 있음(4차). 표 안 표시는 5장 P4 제안 |

## 5. 프로세스: 반영할 만한 것

디자이너 흐름: 홈 → 01 브리프 → 02 기획 방향(이유·콘셉트·대표 카피 + 제안 근거) → 03 상품·혜택 → 구좌 편집 → 04 미리보기·공유 (레퍼런스는 어디서나)
우리 흐름: 캘린더·목록 → ① 명분·브리프 → ② 상품·할인 → ③ 페이지 구성 → ④ 구좌 편집 → ⑤ 확인·전달 (순서 잠그지 않음)

| # | 디자이너에서 본 것 | 우리 상태 | 제안 |
|---|---|---|---|
| P1 | 대표 카피(기획 카피): 브리프와 문서 표지에 들어감 | 없음. 메인 비주얼 카피가 대신함 | ① 브리프에 '대표 카피' 한 칸 추가, ⑤ 문서 표지에 표시. **저장 형식에 칸 추가 필요** → 결정 |
| P2 | 기획 방향 단계의 제안 근거 카드 | ① 옆 패널 명분 근거·컨셉 이력(실데이터 기반) | 우리 것 유지. AI 제안 단계는 AI 사용 승인 뒤 |
| P3 | 기획안을 다시 열면 마지막에 보던 화면으로 | 명분 유무로 ① 또는 ② | 기획안별 마지막 단계를 이 브라우저에 기억 (작은 변경) |
| P4 | 가격 '수정됨' 배지: 처음 정한 가격과 달라지면 표시 | 확정 뒤 바뀐 곳은 ⑤에서만 | ② 표에 '확정 뒤 바뀜' 표시 (확정 스냅샷 기준) → 통합 세션 파일 |
| P5 | 레이아웃을 바꿔도 상품을 지우지 않고 미배치로 남김 | 반영함 (④ 미배치 안내) | 완료 |

| P7 | 미정 상태로도 공유 허용 + 내보내기 전 확인창 | 4차 ⑤에 있음 | 문구만 2장 |

| P9 | 레퍼런스: 보기만 하면 바뀌지 않음, '참고자료로 추가'와 '레이아웃 적용'을 나눔, 필터는 선택 | 레퍼런스 보류 | 레퍼런스를 만들 때 그대로 따름 |
