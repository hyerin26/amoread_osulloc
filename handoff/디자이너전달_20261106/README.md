## 실행

1. Python 3.11 이상
2. `02_코드/amoread_app/run_planner.bat` 더블클릭 → 처음에는 가상환경을 만들어요(몇 분). 끝나면 브라우저가 http://127.0.0.1:9731 로 열려요
3. 기획안 목록에 예시 기획안 4개가 들어 있어요 (`planner/data/projects/`)

데이터(`data/`, `planner/data/`)의 원가·매출·리뷰는 **전부 가상**이에요. 상품명·정가·할인율만 몰 공개 정보예요. 화면의 숫자를 실제 값처럼 쓰지 말아 주세요.

## 꼭 지켜 주세요 (보안 정책 CSP)

서버가 `style-src 'self'`, `script-src 'self'`로 막고 있어요. 아래처럼 쓰면 화면에서 **조용히 무시돼요**.
- HTML의 `style="…"` 속성 → CSS 클래스로 써 주세요 (JS에서는 `el.style.x = …`만 가능)
- `onclick="…"` 같은 인라인 이벤트, `<script>` 안에 바로 쓴 코드 → `.js` 파일 + `addEventListener`
- 외부 CDN 글꼴·스크립트 → `planner/static/` 안에 파일로 넣기

## 합칠 때를 위해

- 이 전달본 이후 기획 쪽에서도 `am.css`, `js/am/*` 등을 계속 고쳐요. 같은 파일을 양쪽에서 고치면 사람이 직접 합쳐야 해요
- 그래서 **토큰·컴포넌트(`tokens.css`, `ds.css`)를 중심으로** 고쳐 주시고, 화면 파일을 고치셨다면 어떤 파일을 왜 고쳤는지 짧게 적어 주세요
- 클래스 이름이나 토큰 변수 이름을 바꾸거나 지우면 JS와 다른 CSS가 깨질 수 있어요. 이름을 바꿀 때는 목록으로 알려 주세요
- 파일을 새로 만드는 것은 합치기 쉬워요
