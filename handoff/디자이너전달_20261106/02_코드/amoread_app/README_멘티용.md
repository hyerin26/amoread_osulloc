# 프로모션 기획 도우미 — 멘티용 복사본

오설록몰 프로모션 기획 도우미(로컬 웹앱)를 디벨롭 실습용으로 복사한 폴더입니다.
**원가·매출 숫자는 전부 가상 데이터**예요. 파일 형식(시트 이름, 헤더, 열 순서, 날짜 표기)은 실제 원천 파일과 같아서,
나중에 실제 파일로 바꿔 끼워도 코드는 그대로 돌아갑니다.

## 실행

1. Python 3.11 이상 설치
2. `run_planner.bat` 더블클릭
   - 처음엔 `.venv` 가상환경을 만들고 패키지를 설치합니다 (몇 분 걸려요)
   - 데이터(`planner/data/planner_data.json`)를 만든 뒤 브라우저가 열립니다 → http://127.0.0.1:9731
3. `data/` 원천 파일을 바꿨으면 `build_data.bat`으로 다시 만듭니다

AI 기능(기획안 만들기·수정 대화)은 이 PC에 **Claude Code가 설치·로그인**돼 있어야 동작합니다.
한 번 부를 때 시간이 꽤 걸리고 사용량이 차감되니 필요할 때만 쓰세요. 나머지 화면은 AI 없이 동작합니다.
네이버 검색 트렌드는 API 키가 없어 비어 있습니다 (`.env`에 `NAVER_CLIENT_ID`/`NAVER_CLIENT_SECRET`을 넣으면 켜짐 — 키는 절대 코드에 쓰지 마세요).

## 폴더

| 위치 | 내용 | 실제 원천 |
|---|---|---|
| `data/report_service/CustomTemplate 고객판매실적_seq YYYY.csv` | SEQ × 일자 판매실적 (**가상**) | 리포트 서비스(태블로) 다운로드 |
| `data/report_service/일자별트렌드_전체 데이터_YYYY.csv` | 몰 전체 KPI (**가상**) | 〃 |
| `data/sample/★오설록 온라인 가이드(샘플)….xlsx` | 상품장 — 이동평균가 = 원가 (**가상 원가·재고**) | MD 온라인 가이드 |
| `data/sample/BY26 프로모션별 할인정보(샘플).xlsx` | PROMO_WORK(행사 이력) + SEQ_MASTER(상품 구성) | 공유 xlsm (읽기만) |
| `data/sample/reviews/` | 고객 리뷰 (**가상 문장**) | 리뷰 주간 수집기 |
| `planner/data/sap_sales_*` | SAP 실적 요약 (**가상**) | SAP 자동 수집 |
| `planner/` | 프로그램 (FastAPI 서버 + static 화면) | — |
| `ops/` | 원본 통합 프로젝트에서 필요한 모듈만 뽑은 것 (엑셀 읽기·설정) | — |

상품명·정가·행사 할인율은 몰에 공개된 정보라 그대로 두었고, 2026-11-03 이후 시작하는 행사는 뺐습니다.
가상 매출은 요일·계절·할인율에 따라 반응하도록 만들어서 '반응도', '레버' 화면이 그럴듯하게 보이지만, **실제 경향을 뜻하지 않습니다.**
화면에서 본 숫자를 보고서·발표에 실제 값처럼 쓰지 마세요.

## 디벨롭할 때 참고

- 숫자 계산은 `planner/engine.py`, 원천 읽기는 `planner/sources.py`, 데이터 만들기는 `planner/build.py`
- 화면은 `planner/static/` (CSP 때문에 HTML `style=` 속성 대신 CSS 클래스·CSSOM 사용)
- 기획 배경·디자인 방향: `planner/DESIGN.md`, `planner/PLAN_v5_개편.md`
- 원천 파일은 **읽기만** 하는 원칙을 지켜 주세요 (실제 공유 엑셀은 여러 명이 같이 편집합니다)
