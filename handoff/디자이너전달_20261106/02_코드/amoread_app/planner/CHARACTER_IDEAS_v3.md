## 1. 레퍼런스 캐릭터는 실제로 이렇게 생겼다 (확인한 사실)

| 항목 | 레퍼런스 (Oh!bot) | 지금 찻잎이 |
|---|---|---|
| 외형 | **3D 렌더 캐릭터**. 흰 고양이·강아지·여우·판다·카멜레온·돼지·사람 7종 중 하나가 무작위로 나온다. 털·조명·그림자가 있는 픽사풍이다 | 64px 평면 SVG. 도형 9개(잎 + 찻잔), 그림자·질감 없음 |
| 움직임 | **애니메이션 WebP 40프레임 · 4.9초 반복**: 눈 깜빡임, 타이핑, 고개 돌리기, 꼬리 | 정지 상태. 마우스를 올리면 6도 기울어지는 게 전부 |
| 이야기 | 전원이 **노트북 앞에서 일하는 팀원**이다. "이 대시보드를 위해 누가 일하고 있다"는 장면이고, 7종이 팀원 캐릭터로 보인다 | 찻잔 위 찻잎. 하는 일이 없다 |
| 상태 표시 | 머리 위 배지 3종: **`!`**(빨강·알림), **`…`**(파랑·답 쓰는 중), **`✓`**(초록·답 완료) | 숫자 배지 하나 |
| 배치 | 원형 버튼 없이 **표 모서리에 걸터앉은 것처럼** 놓였다. 약 70~80px. 화면에 **사는** 느낌 | 흰 원형 버튼 안 64px. **위젯(FAB)** 느낌 |
| 말풍선 | 흰 카드형. 새 기능 안내("인사이트 대시보드가 생겼어요"), 사용법("저를 누르면…")이 번갈아 나온다 | 검은 띠 한 줄, 처음에 한 번 5초 |
| 클릭하면 | **메뉴 카드 3장**(이모지 + 제목 + 한 줄 설명): 💬 대화하기 / 🌅 오늘의 업데이트 / 📊 인사이트 보드 | 바로 서랍이 열리고 '빠른 답 / Claude 기획' 모드 칩이 보인다(용어가 어렵다) |
| 대화창 첫인상 | 이름 **Oh!bot** + 상태 점 + "실적·리뷰·시장·SNS 도우미". 인사는 **2줄** | 인사 4줄 + 모드 설명 + 알림 카드 4장이 한꺼번에 나온다 |
| 답 형식 | **결론 1줄**(숫자 굵게·▲색) → 작은 표 → "가장 많이 오른 곳 ○○" 한 줄 → **기준 각주**(기간·단위) | 문장 + 촘촘한 표 + 담기 버튼. 결론 한 줄이 없다 |
| 기다림 | 보내면 `…` 배지와 "작업 중" 연출(약 1.2초) 뒤에 답한다 → **일하는 느낌** | 즉시 답(빠른 답)하거나 스피너(Claude) |
| 질문 칩 | 아래 고정 3개 ("이번 달 실적 어때?", "지난주 채널별", "25년 추석 대비 26년 추석") | 7~8개. 줄이 넘친다 |
| 전송 버튼 | 입력창 안 주황 원형 ↑ | 입력창 밖 초록 '보내기' 버튼 |

**레퍼런스의 약점** (우리가 더 잘할 수 있는 곳)
- "이번 주 **말차** 판매 어때?"에 말차를 빼고 **전체 채널 매출**로 답했다.
- "오늘 뭐부터 봐야 해?"에 **전일 매출**로 답했다.
- 정규식으로 기간·지표만 잡는 방식이라 상품·의도를 무시한다.
- 즉, **겉모습과 연출은 훌륭하지만 질문 이해는 약하다.** 찻잎이는 반대로 이해는 낫고 겉모습이 약하다.

## 2. 찻잎이가 '구린' 이유 — 6가지

1. **렌더 품질 차이**
   - 3D 렌더 + 40프레임 애니메이션과 64px 평면 아이콘은 같은 자리에 놓으면 급이 다르다.
   - 귀여움의 문제가 아니라 **질감·조명·움직임의 부재**다.
2. **이야기가 없다**
   - 레퍼런스 캐릭터는 "노트북으로 일하는 팀원"이다.
   - 찻잎이는 아무것도 하지 않는 장식이라 **역할이 몸짓으로 보이지 않는다.**
3. **상태가 없다**
   - 레퍼런스는 `!`·`…`·`✓`로 지금 무슨 일이 일어나는지 캐릭터가 알려준다.
   - 찻잎이는 늘 같은 얼굴이다.
4. **위젯처럼 놓였다**
   - 원형 버튼 안에 갇혀 있으니 "채팅 위젯 아이콘"으로 읽힌다.
   - 레퍼런스는 화면 위에 걸터앉아 **같은 공간에 사는 존재**로 읽힌다.
5. **말이 길고 딱딱하다**
   - 모드 이름('빠른 답(데이터 조회)', 'Claude 기획'), 긴 인사, 알림 카드 4장이 한꺼번에 나온다.
   - 대화가 아니라 설정 화면처럼 보인다.
6. **기다림·반응 연출이 없다**
   - 생각하는 척, 끝났을 때의 반응(✓), 칭찬 같은 작은 보상이 없어서 **주고받는 재미**가 없다.

## 3. 왜 이미 만든 스킬 인사이트를 못 썼나 (반성)

- **스킬을 '규칙'으로만 읽었다.**
  - character-alert-ui에서 출처 표기(T0~T4)와 알림 빈도처럼 **정확성 규칙만** 가져왔다.
  - 사례 파일(case-editorial-dashboard)에 적어 둔 관찰은 구현할 항목으로 바꾸지 않았다.
    - 애니메이션 WebP 7종 무작위
    - CSS keyframes를 타이머로 붙였다 떼기
    - 클릭 메뉴 3장
    - 38초 말풍선
    - 1.2초 작업 중 연출
- **대체안에서 멈췄다.**
  - 스킬에는 "권리 불명 이미지는 쓰지 말고, 에셋이 없으면 단순 도형으로 시작"이라고 적혀 있다.
  - "시작"을 "끝"으로 써 버렸다. 에셋을 **어떻게 구할지**(이미지 생성 → 애니메이션 변환) 제안했어야 했다.
- **나란히 비교하지 않았다.**
  - ui-render-review 단계에서 우리 화면만 찍고 **레퍼런스와 같은 크기로 비교**하지 않았다.
  - 오늘 처음 나란히 놓고 보니 차이가 바로 보였다.
- **고칠 점**: 스킬 사례 파일에 "캐릭터 구현 체크리스트"를 추가한다(§6). 다음부터는 서술형 관찰이 아니라 **체크 항목**으로 쓰이게 한다.

## 4. 찻잎이 v3 설계

### 4-1. 외형 — 에셋 만드는 길 (권리 문제 없이)

**에셋 만드는 순서**
1. AI 이미지 생성으로 3D 렌더 캐릭터 정지 이미지 만들기
2. 이미지→영상 도구로 2~5초 반복 동작 만들기
3. 배경 제거 → **애니메이션 WebP**로 변환(Python 스크립트로 제가 처리)
4. 상태별로 몇 개 만들기

**방향 3안**

| 안 | 내용 | 장점 | 확인할 것 |
|---|---|---|---|
| **A. 찻잎이 리뉴얼** | 제주 차밭에서 온 **찻잎 요정**. 둥근 잎 머리, 작은 앞치마, 노트북 앞에서 기획 중. 3D 렌더 | 오설록다움, 기획 도구와 이야기가 맞음 | 이미지 생성 도구 |
| B. 팀 세트에 합류 | 레퍼런스처럼 **기획자 본인의 동물 캐릭터**가 노트북 앞에 있음 | 팀 대시보드와 한 세계관 | 레퍼런스 7종에 본인 캐릭터가 있다면 원작자(대시보드 제작자) 허락 후 그대로 쓰는 게 가장 빠름 |
| C. 티 소믈리에 | 차를 우리는 작은 동물(다람쥐 등) + 찻주전자 | 차 우리는 동작 = "생각 중" 연출과 연결 | 이미지 생성 도구 |

**추천은 A.** 이유는 세 가지다.
- 도구 이름(기획 도우미)과 역할(기획을 같이 우림)에 맞다.
- "차 우리기"를 생각 중 동작으로 쓸 수 있다.
- 팀 캐릭터와 겹치지 않는다.

**상태별 동작 (WebP 5개 + CSS 배지)**

| 상태 | 동작 | 언제 |
|---|---|---|
| 대기 | 눈 깜빡임, 찻잔 김, 노트북 타이핑 (반복) | 평소 |
| 생각 중 `…` | 찻주전자로 차 우리기 / 빠른 타이핑 | 답 쓰는 중, Claude 기획 중 |
| 알림 `!` | 고개 들고 손 흔들기 | 중요 알림이 있을 때 |
| 완료 `✓` | 끄덕임 + 엄지 | 답 완료, 기획안 오류 0개가 됐을 때 |
| 졸림 `z` | 하품 | 데이터가 3일 넘게 안 갱신됐을 때 |

- `prefers-reduced-motion`을 켠 사용자에겐 첫 프레임만 정지 이미지로 보여준다.
- 이미지 생성 프롬프트(영문·한글)와 변환 스크립트는 제가 준비한다.

### 4-2. 배치·행동

- **원형 버튼을 없앤다.**
  - 지금: 오른쪽 아래 흰 원 안 64px
  - v3: 화면 오른쪽 아래 **콘텐츠 모서리에 걸터앉게**, 90~110px. 드래그로 옮기고 위치를 기억한다. [숨기기]를 두면 작은 잎 손잡이만 남는다.
- **클릭 → 메뉴 카드 4장** (레퍼런스 방식)
  - 💬 **대화하기**: "숫자는 바로, 기획은 Claude랑 같이"
  - 🌱 **이번 주 아이디어**: "월요일마다 새로 우려 둔 기획 n개"
  - 🔔 **오늘의 체크**: n건 (배지)
  - 📈 **바깥 소식**: "이번 주 뜨는 것 n개" (트렌드 스카우트)
- **말풍선 로테이션**
  - 약 40초마다 한 번, 같은 문장은 하루에 한 번만 나온다.
  - 말풍선 끄기를 둔다.
  - 출처를 섞되 작게 표시한다.
    - T0 안내: "저를 누르면 이번 주 아이디어를 볼 수 있어요"
    - T1 숫자: "오늘 월요일이에요 — 평소보다 1.4배 팔리는 날" / "프리미엄 말차, 마지막 특가 72일 전이에요. 지금 걸면 반응 클 때예요"
    - T2 주간 AI: "이번 주엔 '두쫀쿠'가 떠요. 진한 단맛엔 세작 한 잔 어때요?" (AI · 10/20 생성)

### 4-3. 대화 — 재밌게, 그러나 숫자는 정확하게

- **머리**: 찻잎이 얼굴 + "찻잎이 · 기획 도우미" + 상태 점(초록 = 데이터 최신)
- **모드 칩을 없앤다.**
  - 질문을 보고 알아서 고른다.
    - 데이터로 답할 수 있으면 즉시(규칙)
    - "기획 짜줘·다듬어줘·아이디어" 같은 요청이면 "Claude랑 우려 볼까요? (1~2분)" 확인 버튼
  - '빠른 답 / Claude 기획'이라는 단어는 화면에서 뺀다.
- **인사**: 2줄 + 오늘 한 줄
  ```
  안녕하세요, 찻잎이예요 🌱
  숫자는 바로 찾아 드리고, 기획은 같이 우려 볼게요.
  └ 오늘: 월요일(평소 1.4배) · 하루특가 빈 날 3일 · 입동 D-6
  ```
- **답 카드 형식** (레퍼런스에서 가져옴)
  ```
  [결론 1줄]  프리미엄 말차, 마지막 하루특가는 72일 전이에요 — 지금 걸면 반응 클 때예요.
  [작은 표]   할인 30% 1.6배 · 35% 4.4배 · 36~40% 카테고리 기준 12배 (근거 n건)
  [한 줄]     원가율 45% 선에선 최대 33%까지예요.
  [기준]      행사일 제외 평소 판매 기준 · 2025-09 이후 PROMO_WORK
  [버튼]      기획안에 담기 · 상품 상세
  ```
- **생각 중 연출**
  - 규칙 답: 0.8~1.2초 `…` + "찻잎 고르는 중"
  - Claude: 실제 단계명을 차 비유로 보여준다. 숫자는 그대로 둔다.
    - 상품 찾는 중 → "찻잎 고르는 중"
    - 원가 계산 → "물 온도 맞추는 중"
    - 검증 → "맛보는 중"
- **재미 요소** (모두 실데이터 기반)
  - **찻잎이 퀴즈**(하루 1문제, 레버 학습)
    - 예: "티세트 하루특가, 몇 %부터 반응이 확 뛸까요? ① 25 ② 30 ③ 36 ④ 45"
    - 정답을 고르면 "36~40%에서 13.4배 — 31~35%의 2.6배예요"와 근거 표를 보여준다.
  - **오늘의 기획 한 잔**: 열 때마다 명분 하나 또는 트렌드 하나 또는 레버 하나를 카드로 보여준다. 예: "정월대보름엔 부럼과 세작".
  - **반응**
    - 기획안 오류가 0이 되면 ✓ 동작 + "깔끔하게 우러났어요"
    - 금요일 오후엔 "주말엔 평소의 0.6배만 팔려요 — 월요일 특가 준비는 끝났나요?"
  - **말투**: 존댓말, 짧게(2문장 이내), 차 비유는 가끔(3번에 1번 정도). 과장 금지(오설록 톤 — "대박·미친 할인" 금지).
- **레퍼런스보다 잘할 것**
  - 질문 속 상품·카테고리·기간을 이해한다.
  - 모르면 "그건 데이터로는 못 찾아요. Claude랑 찾아볼까요?"라고 솔직히 말한다.
- **질문 칩 3개**: 상황에 따라 바뀐다. 월요일엔 "이번 주 하루특가 채우기", 시즌 전엔 "블프 작년엔 어땠어?".

## 5. 기획 아이디어 자동 갱신

**지금 상태**
- 아이디어 카드 7종은 고정 규칙이다. 같은 주를 열면 늘 같은 카드가 나온다.
- 새로고침해도 똑같고, 주가 바뀌어도 규칙이 같아 비슷한 구성이 나온다.

**v3 구조**

```
[월요일 08:30 자동 실행 · Windows 작업 스케줄러 (리뷰 수집기와 같은 방식)]
  1 데이터 갱신 (실적·PROMO_WORK 스냅샷)
  2 트렌드 스카우트 (넓은 그물 → 검증)          ← PLAN_v3 §2-2
  3 아이디어 후보 풀 30~50개 생성 (규칙, 무료)
       명분(명분 캘린더·트렌드) × 레버(요일·할인 깊이·쉰 기간) × 상품군(리뷰·작년·급상승·쉰 상품)
```
