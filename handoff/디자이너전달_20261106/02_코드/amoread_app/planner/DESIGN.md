## 2. 누가·언제·무엇을 (Operate 모드)

- 직영몰 기획자 1명. 사무실 밝은 화면에서 **하루 몇 번, 짧게** 연다.
- 실제로 반복하는 일 4가지 (빈도순)
  1. **작년 시즌 행사를 올해 날짜로 다시 짜기** (블프·설·홀리데이…) — 할인율·품목은 작년대로, 안 팔리는 것만 교체
  2. **이번 주·다음 주 하루특가 빈 날 채우기**
  3. **새 명분으로 기획전 만들기** (다가오는 기념일·트렌드)
  4. **끝난 행사 돌아보기** → 다음 할인 깊이 결정
- 결과물은 항상 같다: **PROMO_WORK에 붙일 엑셀 + 팀 공유 요약.**

→ 화면은 "기획 하나를 시작 → 다듬기 → 내보내기"라는 한 줄 흐름을 중심에 두고, 근거 화면(캘린더·상품·성과·트렌드)은 그 흐름에서 필요할 때 여는 곳으로 정리한다.

## 3. 정보 구조 (IA)

```
상단 막대  [오설록 기획]  이번 주 · 캘린더 · 작업대(118) · 상품  |  성과·레버 · 트렌드      실적~10/15 · 원가 26.8월   ⚙설정
            └─ 기획 흐름 ─────────────────────┘   └─ 근거 ──────┘
```

| 화면 | 답하는 질문 | 첫눈에(5초) | 그다음 | 들어가는 길 |
|---|---|---|---|---|
| **이번 주** (첫 화면) | 이번 주 뭘 해야 하지? | ① 할 일 3~5개(빈 날·D-day·회고 대기·작업대 이어하기) ② 기획 시작 3가지 | 이번 주 아이디어 목록(한 줄씩, 펼치면 미리보기) | 앱을 열면 |
| **캘린더** | 언제 비었고 언제 무엇이 오나 | 4주 격자: 상시 막대(녹)·하루특가 수(귤)·명분 칩 | 다가오는 명분 목록 → 기획 시작 | 할 일의 "빈 날" |
| **작업대** | 이 기획안, 내보내도 되나? | 리본(기간 전체의 상시·특가 리듬) + 숫자 4개 + 확인할 것 | 상시 묶음 / 하루특가 날짜별 묶음 표, 행 판정 팝업 | 모든 "기획 시작"의 도착지 |
| **상품** | 무엇을 넣을까 | 목적별 빠른 보기 + 촘촘한 표 | 상품 상세 시트(반응 카드) → 담기 | 작업대 [+ 상품] |
| **성과·레버** | 지난 할인은 먹혔나 | 레버 보드 / 회차 성과 / 계획 대비 | 회차 상세 → 올해로 다시 기획 | 할 일의 "회고 대기" |
| **트렌드** | 바깥에 무슨 명분이 있나 | 새 후보 → 검증 상태 | 감시 키워드·리뷰 | 이번 주 아이디어 근거 |
| 설정(⚙) | 데이터가 최신인가 | 데이터 상태·갱신 | 원가 파일·보자기·명분 사전 | 상단 오른쪽 |

### 기획 시작 3가지 (이번 주·작업대 빈 화면·상단 [+ 새 기획] 공통)
1. **작년 행사 다시 하기** — 행사 이름 고르기(최근 끝난 회차 목록) → 상시/하루특가 → 올해 시작일 → 미리보기(할인율 분포가 작년과 같은지, 교체 n·확인해 볼 것 n) → 작업대로
2. **하루특가 빈 날 채우기** — 캘린더의 빈 날로 이동해 날짜별 후보에서 고르기
3. **아이디어에서 시작** — 이번 주 아이디어 목록으로 이동
(빈 기획안은 작업대에서 [+ 행])

## 4. 화면별 상세

### 이번 주
- 머리: "10월 넷째 주" + 기간. 설명 문단 없음.
- **할 일**(왼쪽 넓게): 행 하나 = 상태 점 + 한 문장 + 버튼 하나. 예) "하루특가 빈 날 3일 (10/22·10/24·10/26)  [채우기]", "블프 D-14 · 준비 시작  [작년 블프 다시 하기]", "작업대: 블프 다시 기획 118행 · 확인할 것 38  [이어하기]".
- **기획 시작**(오른쪽 좁게): 위 3가지를 큰 버튼 목록으로.
- **이번 주 아이디어**: 카드 그리드 → **목록**. 행 = 리본(미니) · 제목 · 왜 지금 · 품목 수 · 평균 할인 · 예상 매출 · [작업대로]. 행을 누르면 그 자리에서 펼쳐 품목 표·근거를 보여 준다(모달 없음). 좋아요/별로/이미 함은 펼친 영역 아래 글자 버튼.

### 작업대
- 머리: 제목(입력) · 출처·저장 상태 / 오른쪽 [불러오기] [저장] [공유] **[엑셀 내보내기]**. 확정은 [저장] 옆 보조.
- 기획 메모(명분·컨셉·고객·목표): 한 줄 접이식, 비어 있으면 "기획 메모 쓰기".
- **개요 띠**: 리본(시그니처) + 숫자 4개(행 수 상시/특가 · 예상 매출 범위 · 평균 할인 · 확인할 것). 원가율 평균은 숫자에서 빼고 표 열·팝업에만(참고 지표).
- **표**: 기본 정렬 = 유형·날짜. 상시 묶음 머리줄, 하루특가는 날짜 머리줄(요일·품목 수, 5개 이상이면 분산 표시). 판정 배지 → 팝업.
- 빈 화면: 기획 시작 3가지를 그대로 보여 준다.

### 작년 행사 다시 하기 (새 대화상자)
- 1단계 고르기: 행사 이름 검색 + 최근 끝난 시즌 회차 목록(이름 · 작년 기간 · 품목 수 · 행사 매출). 상시/하루특가 체크, 올해 시작일(기본: 같은 요일 364일 뒤 또는 올해 같은 이름으로 잡힌 행사 시작일).
- 2단계 미리보기: "작년 할인율 그대로" 분포 막대(작년 vs 올해 나란히) · 유지/교체/확인해 볼 것/뺌 · 교체 목록 · 원가율 참고 목록 → [작업대로 불러오기].

### 캘린더 · 상품 · 성과 · 트렌드
- 구조는 유지하고 시각 규칙만 맞춘다: 상시=녹, 하루특가=귤, 명분=먹 테두리 칩. 꼬리표·hover 떠오름 제거, 캡션 12px 이상.
- 성과·레버 모드 칩 → 밑줄 탭(같은 화면 안 전환이라는 것을 보이게).

## 5. 시각 규칙

선택: **"찻잎 작업대"** — 제주 차밭의 짙은 녹색 막대 + 밝은 회녹 바탕 + 흰 작업면. 상시는 녹차, 하루특가는 제주 귤색.
기본값 점검(frontend-design): 크림 바탕+테라코타(×) · 검정+형광 1색(×) · 신문 괘선(×) · 같은 카드 반복(×) · 영문 대문자 꼬리표(×) → 모두 피함.

- 글자: Pretendard Variable(자체 호스팅, OFL). 단계 12 · 13 · 14(본문) · 16 · 19 · 24px. 숫자는 tabular-nums·오른쪽 정렬.
- 간격: 4px 기반 4·8·12·16·24·32.
- 모서리: 작업면 10px, 컨트롤 7px, 칩 999px. 그림자는 겹쳐 뜨는 것(팝오버·시트·대화창)에만.
- 움직임: 150~200ms 상태 전환만. 카드 hover 떠오름 없음. prefers-reduced-motion 존중.
- 아이콘: 이모지 대신 직접 그린 SVG(선 1.6px) 한 벌 — core.js `icon()`.
- 시그니처 **행사 리본**: 날짜 칸 한 줄에 상시 막대(녹)와 하루특가 점(귤, 개수만큼)을 그린 띠. 작업대 개요·아이디어 행·작년 다시 하기 미리보기·캘린더 범례가 같은 모양을 쓴다.

## 6. 유지하는 이전 결정
- 숫자는 서버(engine) 한 곳에서. 화면은 표시만.
- CSP `default-src 'self'` → 외부 CDN·인라인 style 금지(폭은 data-w → CSSOM).
- 재고는 쓰지 않는다. 원가율 45%는 참고선(넘어도 '주의').
- 색만으로 상태를 전하지 않는다(✓ ! ✕ 글자 병기).
- 찻잎이는 오른쪽 아래 한 곳. 표 위에 장식을 겹치지 않는다.
