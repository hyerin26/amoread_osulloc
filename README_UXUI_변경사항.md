# UX/UI 변경 사항 (`design` 브랜치)

기획자 프로토타입(`sub` 브랜치 `e7bec8c`)에서 새 버전 화면(`/v2/`)의 UX/UI가 무엇이 어떻게 바뀌었는지 정리한 문서입니다.

- **대상:** `workspace/amoread_app/planner/static/v2/` 화면 8개 (홈, 브리프, 구좌 구성, 구좌 편집, 미리보기·내보내기, 상품·할인, 레퍼런스, 설정)
- **디자인 기준:** AMOREAD Green UI v2.5.1 (`static/tokens.css`, 공통 요소는 `v2/shell.css`·`v2/shell.js`). 새 색·크기 값은 만들지 않습니다.
- **그대로 둔 것:** 데이터 연결, 계산, 저장 형식, 내보내기, 화면 이동 순서
- **갱신 규칙:** `design` 브랜치에 변경이 올라갈 때마다 아래 **변경 이력** 맨 위에 한 묶음을 더합니다. 자세한 원인·확인 내용은 각 묶음에 적은 `plans/` 문서에 있습니다.

## 변경 이력 (최신이 위)

### 2026-11-10 · 좁은 화면의 구좌 편집·미리보기 보완
- 브리프: 레퍼런스 상세 패널은 자세히를 누를 때만 열어요.
- 구좌 편집: 중간 너비에서는 편집 패널을 옆에서 열고, 휴대폰 너비에서는 구좌 목록도 접어요. 상품 선택 창은 편집 패널 위에 표시돼요.
- 미리보기·내보내기: 한 열에서는 내보내기 영역이 문서와 함께 스크롤돼요. ZIP 선택 항목은 체크박스 옆에 파일명과 설명을 두 줄로 정렬해요.

### 2026-11-10 · 문구 다듬기
- 홈 새 기획안 시작 창의 기간 안내: 「보통 프로모션 길이」 → 「일반적인 프로모션 길이」 (3곳)

### 2026-11-10 · 전체 UX/UI 개선·버그 수정 — 자세히: `plans/25_전체_UX_UI_개선_버그수정_20261110.md`
- **레퍼런스:**
  - 상세 이미지·글 겹침 수정
  - 서버 저장소: 직접 추가, 이미지 올리기, 즐겨찾기
  - Pinterest 공개 보드(RSS) 구독 → 핀 담기
  - 「직접 입력」
  - 「즐겨찾기만」
- **브리프:**
  - 레퍼런스 상세 옆 서랍 (공통 `.v2drawer`)
  - 마인드맵 클릭 펼치기·접기, 동그라미로 복수 선택 (펼친 키워드가 다시 눌러도 안 접히던 버그 수정)
  - 문구 정리
- **구좌 편집:**
  - 카드 ID 겹침으로 상품이 섞이던 것 수정
  - 여러 카드 동시 펼침
  - 구좌 추가·복제·삭제
  - 실행 취소·다시 실행
  - 화면을 떠날 때 저장
  - 라이브러리 레퍼런스 연결
- **홈:**
  - 기간 이동 화살표·문구
  - 빈 기간 문구
  - 클릭 두 번 기간 고르기
  - 시작 창 상품 검색
- **미리보기:** 확인 항목 이름·이유, 내보내기 위로
- **반응형:**
  - 편집 패널이 좁은 화면에서 밖으로 밀리던 것
  - 카드 열 넘침
  - 폰 폭 윗줄
  - 중복된 이전·다음 버튼 제거
- **동작하는 척하던 버튼 정리:** 실제로 연결하거나, 「준비 중」으로 표시하거나, 없앰

### 2026-11-09~10 · 사내 UI v2.5.1 적용·가독성·길잡이 — 자세히: `plans/24_사내UI_v2.5.1_가독성_길잡이_개선.md`
- **글꼴:** Inter + Pretendard, 미리 받기, 서버 글꼴 캐시 (깜빡임 제거)
- **디자인 시스템:**
  - 선택 표시는 1px 초록 선(`--sel-line`)
  - 행사가는 `--price`
  - 입력칸 포커스는 테두리 색만
- **읽기 크기:** 본문 15/24 · 작은 본문 14/22 · 보조 13/20. 한글 낱말 중간 줄바꿈 금지
- **일관성:** 칩·탭·버튼 높이와 여백 통일
- **길잡이:** 단계 막대 [다음] 하나, 끝난 단계 체크, 제목 = 지금 연 기획안 이름
- **데이터 출처 표시:** 노란 띠 → 윗줄 작은 표시
- **아이콘:** 기호 → SVG 한 벌
- **홈:** 명분 이름 겹침 배치, '오늘' 줄
- **구좌 편집:** 실제 데이터 표시 약 23초 → 약 1초 (리뷰 요약 캐시)
