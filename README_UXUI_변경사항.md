## 변경 이력 (최신이 위)

### 2026-11-16 (6) · 마인드맵: 가지만 남기고 노드는 손대기 전으로

- 사용자 의견("손대기 전이 나았음, 가지 모양만 고친 게 나음")에 따라 노드 모양·크기·색·간격·지도 크기 계산을 통합 브랜치(merge/2026-11-15) 그대로 되돌림
- 남긴 것: 괄호형 가지 선(세로 기둥 공유·꺾임만 둥글게), 굵기 1단 1px · 하위 0.75px, 가운데→보고 있는 키워드 길 초록 1.25px, 누를 때 검정 초점 테두리 없앰
- 스크롤 줄이기로 바꾼 지도 위 도구 한 줄 정리·안내 문장 제거는 그대로

### 2026-11-16 (5) · 마인드맵: 누를 때 검정 테두리 없앰, 가지 선 가늘게

- 누르면 다시 그리며 초점을 되돌려 놓아 브라우저 기본 검정 초점 테두리(3px)가 붙던 것 없앰. 키보드로 옮길 때만 초록 2px
- 고르기 동그라미의 누르는 영역(보이지 않는 네모)에 노드 테두리 규칙이 같이 걸려 생기던 진한 네모 없앰
- 선 굵기: 1단 1.5→1px, 하위 1.25→0.75px, 고른 길 2→1.25px

### 2026-11-16 (4) · 마인드맵: 원형 되돌림 → 둥근 네모 + 괄호형 선

- 사용자 의견("원형은 별로, 선만 정리하고 둥근 네모")에 따라 방사형 원을 되돌리고 좌우 배치로.
- **선**: 곡선이 제각각 퍼지던 것을 괄호형으로 — 부모에서 가로로 나와 세로 기둥 하나를 같이 쓰고, 꺾이는 곳만 반지름 8로 둥글게. 같은 단계는 한 세로줄(부채꼴 휨 없앰)이라 세로선이 한 줄로 겹쳐 정리돼 보임. 고른 길(초록)은 회색 선 위에 그림
- **모양**: 알약 → 둥근 네모(모서리 8, 가운데 10). 색은 가운데 진한 초록 + 흰 글자 / 1단 연한 초록 / 하위 흰 바탕. 고르기 동그라미는 네모 안 왼쪽 그대로
- 확인: 가지 12개·펼침 1개, 단위 146 · e2e 36 통과
