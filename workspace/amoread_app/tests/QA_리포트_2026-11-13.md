## 2. 고친 것 (이번 점검에서 바로 수정, 검증함)

1. **영문 키워드가 낱말 조각에 반응** — `Desktop banner`가 TOP(큐레이션), `renewal`이 NEW(신제품)로 분류됐어요. 영문 키워드에 낱말 경계 추가 (`rules._kw_re`).
2. **목적·분류만으로 정한 유형이 '신뢰도 중간'** — 예: 목적 '전환·매출' + 분류 '시즌'만 고르면 벚꽃 한정판 티가 '대형 세일(중간)'. 단어 근거가 없으면 '낮음'으로 낮추고 안내 문구 추가.
3. **추천 한 번에 파일을 카드 수×2번 읽음** — `capture_info`가 매번 `refs.json`을 다시 읽어 레퍼런스 8개 추천이 0.21초 → 0.035초로 (수정시각 기준 캐시).
4. **구좌 편집 전용 구좌 종류가 엉뚱한 사례로 연결** — 유의사항·사진 인증·후기·대표1+2열·쿠폰 받기 등 편집 화면에만 있는 13가지가 전부 '스토리' 사례로 갔어요. 이제 유의사항→유의사항 사례, 사진 인증→참여 이벤트, 쿠폰 받기→쿠폰 발급 등으로 연결 (`refs.roles_for`). 실제 기획안으로 재확인.
5. **수집 화면 콘솔 오류 수백 줄** — 수집본을 그릴 때 `<style>`·`style=""`이 CSP 위반으로 기록(막히진 않음), 이미지 주소는 바깥(CSP 오류)·안쪽(`/kr/ko/…` 404)으로 요청됨. 파싱 전에 무해하게 바꾸고 이미지·글꼴 주소는 비움. 라이브러리 구좌 탭 스크롤 시 오류 834건 → 0건.
6. **파비콘 404** — 화면마다 콘솔에 빨간 줄. `/favicon.ico`에 204 응답 추가.
7. **빨리 스크롤하면 지나간 카드까지 그리느라 대기** — 줄 서 있는 사이 화면에서 900px 넘게 벗어난 카드는 건너뛰고 다시 보일 때 그리도록. (화면 한 장당 ≈1초, 14~28장)
8. **구성 화면 문구 3곳이 AI 연결 후에도 예시 문구** — "PROMO_WORK 지난 행사로 N개", "연결 후 AI·로직", 안내 상자의 "C는 아직 예시". AI가 연결됐을 때 실제 동작에 맞게.
9. **'참고로 붙이기/빼기'가 서버 학습으로 안 보내짐** — 서버에 pick_ref/drop_ref 기록·반영 코드는 있는데 화면이 호출하지 않아 학습이 영원히 0이었어요. 연결 (화면 변화 없음, 200 확인).

### 지속성 장치 (코딩 없이도 굴러가게)
- **자체 점검** `amoread/ai/selfcheck.py` — 색인·수집 화면 파일·라벨·유형 통계·기록 파일이 서로 맞는지 확인하고 "할 일 한 줄"을 알려 줘요. 서버 시작 때 한 줄 요약, `/api/am/ai/health`, 라이브러리 맨 위(**오류일 때만**), `python -m amoread.ai.selfcheck`.
- **약속 테스트** `tests/test_contracts.py` — 화면과 서버 사이 약속(구좌 종류↔레퍼런스 역할, API 주소, 피드백 이벤트, 글자 수 한도, 파일 존재, JS 문법)을 자동 확인. 이번에 나온 "구좌 종류가 늘었는데 연결이 안 됨" 같은 문제는 이제 테스트가 먼저 잡아요.
- **품질 성질 테스트** — 점수 식을 고치거나 데이터가 바뀌어도 '추석에 크리스마스 안 나옴', '자사몰 사례가 빠지지 않음'이 깨지면 알려 줘요.
- **화면 훑어보기** `tests/e2e_smoke.py` — 실제 브라우저로 모든 화면을 열어 콘솔 오류·넘침·멈춘 크롭 확인 (지금 문제 없음).
- 운영 원칙·새 기능 더할 때 할 일은 `amoread/ai/README.md`의 "유지보수 없이 굴러가게 하는 장치"에 정리.

### 남은 일 (추후 해결)
- **상품 데이터가 없으면 진짜 기획안 대신 예시가 열려요.** 원가·실적 파일이 없는 PC에서 구좌 편집·미리보기·상품·할인을 열면 저장된 구좌 대신 가상의 예시 구좌가 나오고, 위에는 진짜 기획안 이름과 "저장했어요"가 떠 있어요 (예시를 고쳐도 저장되지 않음). 지금은 화면 위 안내 띠로 알리기만 해요.
  고칠 방향: 예시로 바꾸지 말고 저장된 구좌는 그대로 보여 주고, 상품·원가 칸만 '데이터 없음'으로 두기 (`editor.js` 940줄, `preview.js` 333줄, `deals.js` 520줄 근처의 `PRODUCTS_API.all()` 실패 처리).
- 같은 1초 안에 두 창이 저장하면 충돌을 못 알아채요 (저장 시각이 초 단위). 실제로는 드물어요.
