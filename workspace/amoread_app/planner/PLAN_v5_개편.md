## 2. 원칙

1. **한 화면 = 한 결정.** 한 단계에서 사람이 고르는 것은 하나. 나머지는 접거나 시트로.
2. **운영 콘솔에 있는 건 안 보인다.** 실적·일정·할 일·행사 성과는 콘솔에서. 기획 도우미는 "무엇을·언제·얼마에"만.
3. **숫자는 규칙, 고르기는 사람, 초안·문장은 AI.** AI는 숫자를 만들지 않고, 사람이 고를 후보와 이유를 낸다.
4. **기본은 결론만.** 설명 문장은 화면에서 빼고 ⓘ 팝오버로. 점검은 '확인할 것 N'만 보이고 접힘.
5. taste-skill에서 가져오는 것: 한글 `word-break: keep-all`, 존댓말 통일, 이모지 0(Zone 이름의 이모지 포함), 위계 없는 카드 반복 금지. 가져오지 않는 것: CDN·다크·장식 모션(CSP·업무 도구 성격과 안 맞음).

## 3. 새 정보 구조

```
상단  [기획 도우미]   기획 · 지난 기획 · 근거 ▾(상품 / 성과 / 트렌드)        데이터 ~10/31   ⚙
```

| 화면 | 답하는 질문 | 비고 |
|---|---|---|
| **기획** (첫 화면) | 지금 어떤 기획을 하나, 어디까지 했나 | 4단계 마법사. 진행 중 기획이 있으면 그 단계로 바로 |
| **지난 기획** | 내가 저장한 기획안 목록 | 불러오기·복제·삭제. 지금 작업대 머리의 [불러오기] 셀렉트를 대체 |
| 근거 › 상품 | 이 상품 넣어도 되나 | 표 + 상품 시트. 기획 3단계 [+ 품목]에서 시트로도 열림 |
| 근거 › 성과 | 지난 할인은 먹혔나 | 회차 성과 + 레버(할인 패턴과 합침). '계획 대비 실적' 삭제 |
| 근거 › 트렌드 | 바깥에 명분이 있나 | 새 후보만. 키워드 그룹·질의 편집·네이버 키 안내는 ⚙ 설정으로 |
| ⚙ 설정 | 데이터가 최신인가 | 데이터 갱신·원가 파일·보자기·명분 사전·키워드 그룹·API 키 |

**없어지는 화면/요소:** 이번 주 탭 자체, SAP 실적 KPI, 할 일 목록, 기획 D-day 표·계산 규칙, 4주 캘린더 탭(→ 2단계 안의 달력 시트), 명분 카드 그리드, 조합 추천 별도 화면(→ 3단계 [+ 품목] 시트의 한 탭), 계획 대비 실적, 찻잎이 말풍선·퀴즈·오늘의 체크, 할인 패턴 별도 모드.

## 4. 기획 4단계

화면 위에 단계 막대 `① 무엇을 ─ ② 언제 ─ ③ 품목·할인 ─ ④ 확인·내보내기`. 뒤로 가도 입력은 유지. 단계마다 오른쪽 아래 [다음] 하나.

### ① 무엇을 — "왜 지금?" (사람이 고름)
- 위: **시작 방법 3개** 큰 버튼 — [작년 행사 다시 하기] [새 명분으로] [하루특가 빈 날 채우기]
- 아래: **다가오는 명분 3~5개만** 한 줄씩 — 이름 · D-day · 준비 시작일 · 작년 같은 행사(품목 수·매출) · `이미 잡힘` 배지
- 고르면: 명분·유형(상시/하루특가)이 정해지고, AI [컨셉 문장 3안] 버튼(선택). 고른 문장은 기획 메모로.
- 작년 다시 하기: 목록 기본값을 **올해 같은 시기 작년 행사**(364일 기준 ±21일)로. 지금은 '최근 끝난 행사'라 매번 검색해야 함.

### ② 언제 — 기간·리듬 (규칙이 제안 → 사람이 확인)
- 리본 한 줄 + 시작·종료 날짜 + 하루특가 날짜 칩
- 기본값: 작년 같은 요일 / 명분 날짜에서 역산
- 같은 기간 이미 잡힌 행사: 건수 배지만, 누르면 시트
- 레버 힌트는 한 줄만: "하루특가 하루 3~4개 · 같은 상품 재특가 61일+ 권장" (근거는 ⓘ)
- [달력 보기]를 누르면 4주 달력 시트(지금 캘린더 탭 격자 재사용)

### ③ 품목·할인 (규칙/AI 초안 → 사람이 받거나 뺌)
- 맨 위 **제안 목록**: 작년 다시 하기의 교체·추가, 또는 AI 초안 행. 행마다 [받기] [빼기], 위에 [모두 받기]. (지금은 미리보기에서 교체를 자동 적용 → 사람이 하나씩 정할 수 없음)
- 표 기본 **8열**: 유형 · 날짜 · 상품 · 할인율 · 할인가 · 판정 · 예상 매출 · 메모. 나머지(SEQ·Zone·소구문구·원가율·반응·쉰 기간·털이)는 [열 더 보기].
- 여러 행 선택 → 할인율 일괄 변경.
- [+ 품목] 시트: 상품 검색 / 조합 추천 / 트렌드 후보 탭.
- [AI에게 수정 요청] → **구조화 시트**(아래 5장).

### ④ 확인·내보내기 (사람만)
- `확인할 것 N` (오류 먼저, 펼치면 행별 고치기 버튼)
- 기획 메모(명분·컨셉·고객·목표) 한 칸 묶음
- [공유 요약 복사]
- 주 버튼 하나: **[확정하고 엑셀 내보내기]** (확정 스냅샷 + 엑셀 동시). 지금의 저장/확정/엑셀 3개 혼동 해소. 저장은 자동(초안).

## 5. AI·규칙·사람 역할

| 결정 | 누가 | 방식 |
|---|---|---|
| 명분 후보 | 규칙 | 명분 사전 + 시즌 일정 + 작년 행사. AI 불필요 |
| 명분 고르기 | **사람** | |
| 컨셉·고객 상황 문장 | AI 초안 3안 → 사람 고름 | 짧은 호출(도구 없음, 1회 ~10초). 선택 사항 |
| 기간·리듬 | 규칙 제안 → **사람 확인** | AI 불필요 |
| 품목 초안 | 규칙(작년 다시 하기) 또는 AI | AI는 **고정 양식**으로 요청: 명분·기간·유형·품목 수·카테고리·가격대·뺄 상품·참고 행사. 결과는 '제안 목록'으로 와서 사람이 받기/빼기 |
| 품목 수정 | AI | 구조화 명령 칩(하루특가 n개 추가 / 이 상품 빼고 비슷한 것 / 2만원대로 교체 / 날짜 분산) + 자유 문장 1칸. **항상 현재 기획안 기준**, 화면에 "현재 기획안 n행을 함께 보냅니다" 표시 |
| 할인율 | **사람** (기본값 = 작년 할인율 또는 평소 중앙값) | AI는 이유만 씀. 원가율 때문에 자동으로 깎지 않음(현행 유지) |
| 원가율·겹침·재특가 간격 검증 | 규칙(check_plan) | AI 불필요 |
| AI가 되묻는 질문 | **사람이 답함** | 결과에 질문이 있으면 답 입력칸 → 답을 붙여 다시 실행(지금은 질문을 보여만 주고 끝) |
| 확정·엑셀 | **사람만** | |

AI 호출 바꾸는 점
- 입구를 **문장 정규식 → 버튼**으로. 찻잎이 대화창은 '빠른 데이터 조회'만 남기고 Claude 기획은 3단계 시트에서만 실행.
- 실행 전 고지: "약 1~2분 · 약 $0.7~1 · 현재 기획안 n행 포함".
- 프롬프트는 양식 값을 그대로 구조화해 보낸다(자유 문장은 보조). system_prompt의 규칙은 유지.
- 결과에 행별 `memo`(넣은 이유)를 3단계 제안 목록에 그대로 보여 줌 → 받기/빼기 판단 근거.
